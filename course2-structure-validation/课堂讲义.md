# 第一学时：这条蛋白到底长什么样

## 别把 EGFR 想成一个球

EGFR 全长 1210 个氨基酸（UniProt P00533）。它不是一团均匀的蛋白，而是从细胞外一路贯穿到细胞内的长条：

| 段落 | 大致位置（UniProt 编号） | 干什么的 |
|---|---:|---|
| 信号肽 | 1–24 | 把新合成的蛋白送进分泌系统，成熟后通常被切掉 |
| 胞外区 | 25–645 | 认配体、参与二聚化 |
| 跨膜螺旋 | 646–668 | 穿过细胞膜 |
| 胞内区 | 669–1210 | 包含激酶域和 C 端尾巴 |
| 激酶域 | 约 712–979 | 结合 ATP、催化磷酸化 |
| C 端尾巴 | 979 之后 | 一堆磷酸化位点，负责招下游蛋白 |

胞外区再细分，是 I、II、III、IV 四个结构域。domain I 和 III 参与认配体，domain II 有个二聚化臂，domain IV 贴近细胞膜。西妥昔单抗打的就是 domain III。

让学生画一遍这条线：

```
信号肽 | 胞外 I II III IV | 跨膜 | 激酶域 | C端
```

然后把五样东西贴到对应位置：EGF、西妥昔单抗、厄洛替尼、T790、`1M17`、`1YY9`。

这一步做对了，后面才不会乱。

课上会问："为什么抗体打不到激酶域？"

答案很朴素：抗体是蛋白，进不了细胞膜。要够到胞内的激酶域，得先想办法穿过膜——这不是常规抗体的活。

所以针对 EGFR，两类药物的位置天然不同：小分子钻进胞内激酶域的口袋，大分子贴在胞外表面。今天主要看前一种，课程三换到后一种。

---

## PDB 里为什么都不是全长

搜 EGFR，会看到一堆结构。但打开任何一个，往往只有一段。

原因不复杂。全长 EGFR 又带糖链、又有跨膜螺旋、又有柔性尾巴，这几段需要的表达和纯化条件差别很大。研究者通常只做一段，把想回答的问题回答清楚。

`1M17` 只做激酶域：它要回答"厄洛替尼怎么结合"。

`1YY9` 只做胞外区加一个 Fab：它要回答"西妥昔单抗贴在哪儿"。

这不是偷工减料。片段结构只要研究对象明确，比硬凑一个全长模型可靠得多。

课上问一句："`1M17` 能看到 domain III 的形状吗？"

看不到。它是胞内那段的坐标。反过来，`1YY9` 里也看不到 ATP 位点。

同一个蛋白，不同片段，别混着用。

---

## 打开 1M17

```pymol
load 1M17.pdb, 1M17
hide everything
show cartoon, 1M17 and polymer.protein
```

先看一眼这个条目到底是什么：EGFR 激酶域 + 厄洛替尼，X 射线晶体结构，分辨率 **2.60 Å**，蛋白只有 A 链。

现在找一个坑，这个坑每年都有学生掉进去。

课程里管这个药叫"厄洛替尼"，英语 erlotinib，有人图省事写成 ERT。但**官方 1M17 文件里，这个小分子的三字母名不是 ERT，是 AQ4**。

也就是说，下面这行在官方文件里什么也选不到：

```pymol
select erlotinib, resn ERT
```

正确的写法：

```pymol
select erlotinib, 1M17 and resn AQ4
count_atoms erlotinib
```

`count_atoms` 出个非零的数，才说明你选上了。

那"药物名字"和"文件里的名字"为什么不一样？因为 PDB 里那个三字母代码是化学组分编号，是数据库给这个分子起的内部名字，跟药品通用名不是一回事。以后遇到别的结构也一样，先查文件的 `HETNAM` 或 RCSB 的 Chemical Components，别想当然。

顺便讲讲 2.60 Å 是什么意思，因为这句话经常被念错。

它大致代表"这套衍射数据能分辨到 2.6 Å 这个尺度"。**不等于每个原子的误差都是 2.6 Å**，也不代表所有侧链都长得一样清楚。真要判断质量，还得看电子密度、B 因子、哪些残基干脆没建模。

本科阶段不用逐项查，但别把它写成一个万能的质量保证。

# 第二学时：AlphaFold 模型，哪些地方能信

## pLDDT：这个残基折得像不像

AlphaFold 给的结构，每个残基都带一个分数，叫 pLDDT，画在文件里就是 B 因子那一列。

它回答的问题是："这个残基附近的一小块几何，模型有多大的把握。"

经验上大致这么分：

- 大于 90：一般很靠谱
- 70–90：整体可信，细节别抠太狠
- 50–70：小心
- 小于 50：多半是柔性区、无序区，或者模型也拿不准

两个常见的误解要当场纠正：

第一，低 pLDDT 不等于"这段序列不存在"。很多蛋白本来就有一段是甩来甩去的，没有固定构象，模型当然给不出高分。

第二，高 pLDDT 不等于"能结合药物"。它说的是"形状像回事"，跟亲和力是两码事。

课上打开 AlphaFold DB 的 P00533 页面，让学生分四段看：激酶域、各个胞外结构域、跨膜附近、C 端尾巴。

看完会有一个直观感受：同一张模型，不同区域的分数差别很大。

所以报告里别干"给整条蛋白算个平均 pLDDT"这种事。高分的和低分的搅在一起，平均值什么信息都剩不下。

---

## PAE：两块结构之间的相对位置可靠吗

pLDDT 是"每个零件像不像"，PAE 是"零件之间的相对位置靠不靠得住"。

经常出现这种情况：激酶域内部 pLDDT 很高，胞外各结构域也各自很高，但是结构域之间的关系分数很差——也就是每个部件都折得不错，可它们之间怎么摆的，模型没把握。

对 EGFR 这种多结构域受体，这一点尤其关键。你不能因为全长模型画出来连成一条，就当它是生理状态下唯一的样子。

课上会问："如果你要拿一个全长模型去对接，敢直接当刚性体用吗？"

不敢。至少要把问题拆开，或者找实验结构、找多个构象来对照。

---

## RMSD：这个数字必须带上下文

把预测结构和晶体结构叠一叠，PyMOL 会吐一个 RMSD 出来。

问题在于，这个数字的含义依赖三个东西：你选了哪些残基、对齐了哪些原子、有没有剔掉离群点。

所以这两句话的分量完全不同：

- "两个结构 RMSD 是 1.2 Å。"
- "在双方都有的激酶域 Cα 原子上叠合、剔除离群点后，RMSD 是 1.2 Å。"

后面那句才能被别人重复。

学生常犯的错是拿全长模型直接跟片段结构 `align`，然后盯着一个巨大的数字发愣。原因很简单：一边只有激酶域，另一边还有胞外和跨膜，能对上才怪。

正确的做法是先确定双方共同覆盖的范围。示意一下：

```pymol
select af_kinase, af_egfr and resi 712-979 and name CA
select exp_kinase, 1M17 and chain A and name CA
align af_kinase, exp_kinase
```

**这行只是示意，跑之前一定要先核对两个文件的编号是不是同一套。** 编号问题下一节就讲。

最后提醒一句：RMSD 小，说明整体骨架接近。它不保证 ATP 位点每条侧链都一样，更不保证配体会以同样的姿势结合。

---

## 编号：同一个残基，三个名字

这是今天最重要的技术细节，也是以后最容易出事故的地方。

同一个氨基酸，在 UniProt 里的编号和在 PDB 文件里的编号经常不一样。原因包括：

- 信号肽在成熟蛋白里被切掉了（少 24 个）
- 结构是截短构建体，只保留了一段
- 作者保留了自己的编号习惯
- 有些残基缺电子密度，坐标里干脆没有
- 还有插入编码这种 100A、100B 的写法

`1M17` 就是个活例子。

课本上说的 gatekeeper 残基是 T790（这是 UniProt 的编号）。打开官方 `1M17.pdb`，A 链上第 790 位是什么？

用命令看一眼：

```pymol
select wrong_t790, 1M17 and chain A and resi 790
iterate wrong_t790 and name CA, print(chain, resi, resn)
```

打印出来是 LEU，不是 THR。

真正对应 T790 的是 A 链第 **766** 位：

```pymol
select mapped_t790, 1M17 and chain A and resi 766 and resn THR
iterate mapped_t790 and name CA, print(chain, resi, resn)
```

790 减 766，差 24，正好是信号肽的长度。

但**别把这个 24 当成通用规则**。换一个 PDB 条目，偏移量可能完全不同。唯一靠谱的做法是每次核对，或者用 RCSB 的 mapping、SIFTS 这类工具查。

所以下面的写法是错的：

```pymol
select t790, resi 790
```

这个选择会悄悄选中一个亮氨酸。命令不报错，图也能出，但图上标的是错的。

今天要求学生统一写成：

```pymol
select t790, 1M17 and chain A and resi 766 and resn THR
label t790 and name CA, "T790 (1M17: T766)"
```

多写一个 `resn THR` 不是啰嗦。它的作用是：万一编号错了，选择会是空的，而不是偷偷选中别的残基。空的选择你一眼就能发现，错误的残基你可能一整节课都发现不了。

同理，L858R 的 L858 在官方 `1M17` 里对应 A 链 834 位：

```pymol
select l858, 1M17 and chain A and resi 834 and resn LEU
```

课上让学生自己跑一遍这两对映射，然后把结果记到结构档案里。记的时候带上来源：UniProt 是哪个版本、PDB 是哪个条目。

# 第三学时：三个视角，加上一段 AI 协作

## 每张图都要回答一个问题

结构图的通病是"好看但没用"。今天只做三张，每张都必须能说清楚它要回答什么。

### 视角一：激酶域和配体

```pymol
hide everything
show cartoon, 1M17 and chain A and polymer.protein
color grey80, 1M17 and chain A and polymer.protein
select erlotinib, 1M17 and resn AQ4
show sticks, erlotinib
color orange, erlotinib
```

回答的问题：厄洛替尼在哪？

（这里就直接用整条 A 链，别去选什么 `resi 709-968`。**709–968 是 UniProt 的编号，1M17 是另一个编号体系**，直接套上去就选错段了。这个坑上一节刚讲过。）

### 视角二：5 Å 邻域

```pymol
select pocket5, byres ((1M17 and chain A and polymer.protein) within 5 of erlotinib)
show sticks, pocket5
color cyan, pocket5
count_atoms pocket5
```

回答的问题：配体周围都挨着谁？

`byres` 这一步很多人会漏。不写它，画面上只会出现"挨得近的那几个原子"，一段一段的，看着像被打碎了。加上它，才把接触原子扩展回完整残基。

数一下 `count_atoms` 的结果，几十个残基是正常的。如果只有两三个，八成是选择写错了。

顺便说一句：5 Å 是我们这节课自己定的工作阈值，不是实验测出来的口袋边界。论文里有人用 4 Å，有人用 6 Å，都行，但你得写清楚自己用了多少。

### 视角三：T790

```pymol
show sticks, t790
color magenta, t790
label t790 and name CA, "T790 (1M17: T766)"
zoom (erlotinib or pocket5 or t790), 7
```

回答的问题：T790 在什么位置？

看一眼就知道，它就在配体旁边，是口袋"门口"的那一类位置。

截图之后，让学生写一句："这张图能说明什么？"合格的答案是"T790 位于抑制剂结合区域附近，说明它突变后可能影响结合"。不合格的答案是"这证明了 T790M 导致耐药"——一张野生型的静态图证明不了耐药机制。

## 让 AI 写脚本，但事实得你自己喂

这门课允许用 AI 写 PyMOL 命令。但有个前提必须先说清楚：

**AI 只负责把需求翻译成语法，不负责知道 1M17 的链是 A、配体叫 AQ4、T790 是 766。**

你要先把事实整理成一张表：

| 项目 | 值 | 从哪来的 |
|---|---|---|
| 对象名 | `1M17` | PyMOL 对象列表 |
| 蛋白链 | A | RCSB / PDB 文件 |
| 药物 | 厄洛替尼 | RCSB Chemical Components |
| 配体 resn | `AQ4` | `HETNAM` / `HETATM` 记录 |
| canonical 位点 | T790 | UniProt P00533 |
| PDB 中的位置 | A 链 766 位，THR | 编号映射核对 |
| 阈值 | 5 Å | 本次课堂约定 |

然后这样问：

```
根据下面这些已经核对过的事实，写一个 PyMOL 脚本。

对象名 1M17，蛋白链 A，厄洛替尼的 resn 是 AQ4，
canonical T790 对应 1M17 的 chain A / resi 766 / resn THR。

要求：
1. 建立 erlotinib、pocket5、t790 三个命名选择；
2. pocket5 用 5 Å，并且扩展到完整残基；
3. 三个选择各跑一次 count_atoms；
4. 蛋白画 cartoon，配体和邻域画 sticks；
5. 标签写成 "T790 (1M17: T766)"；
6. 白底，输出 student_view.png，dpi=300。

不要自己改链号、配体名或者编号。
```

拿回来以后，逐条过：

- [ ] 每个选择的原子数是不是非零
- [ ] `t790` 选出来的残基名是不是 THR
- [ ] `pocket5` 是不是围着配体，而不是散在全蛋白上
- [ ] 图里是不是只出现一个 T790 标签
- [ ] 有没有偷偷把编号换成 790 或者把 resn 写成 ERT

最后把 AI 初稿、你发现的问题、你的修改、修改后跑出来的数字，全部写进 `ai_pymol_review.md`。

教师演示的时候可以故意给一版"看起来合理"的坏脚本：

```pymol
select ligand, resn ERT
select t790, resi 790
```

先不说答案，让学生自己用 `count_atoms` 和残基名去查。查到之后，他们这辈子都会记得查 `HETNAM` 这件事。

# 第四学时：口袋、耐药，还有隔壁那节课

## 口袋检测：别把分数当结论

用 DoGSiteScorer 上传 `1M17.pdb`，它会给出几个口袋和各自的体积、分数。

要提醒的是：这些都是**工具在特定构象和预处理下算出来的数**，不是"可成药性证明"。换一个算法、换一个构象、加不加配体，结果都可能变。

判读的时候按这个顺序：

1. 排在前面的是不是 AQ4 所在的那个口袋？
2. 如果是，说明工具的检测和已知结合位点对得上——这是好事；
3. 如果不是，也别一口咬定工具错了，先回头查：文件传对了吗？配体还在吗？口袋是按体积排的还是按分数排的？

课上让学生把"数值"和"解释"分两栏写。解释必须写成条件句，比如：

> 在 1M17 这个构象和当前预处理下，排名第一的口袋与厄洛替尼所在的 ATP 位点空间重合，支持该位点具有小分子可结合的几何特征。

最后半句"支持"和前面那些限定词，都不能省。

---

## T790M：别只会说"位阻"

课本上常常这么说：T790 是"看门人"残基，突变成甲硫氨酸以后侧链变大，把药顶出去了。

方向没错，但不完整，而且这么讲容易让学生以为记住一句话就够了。

实际上 T790M 耐药还牵扯：

- 突变后的激酶对 ATP 的亲和力可能变高，可逆的 ATP 竞争性抑制剂就更难抢过 ATP；
- 口袋局部的疏水环境变了，不同药物受影响的程度不一样；
- 激酶的构象平衡会变，偏好活性构象的抑制剂和偏好非活性构象的抑制剂，受影响方向可能不同；
- 细胞内的药物浓度、ATP 浓度、旁路信号激活，都会叠进来。

第三代抑制剂的思路之一，是利用 C797 形成共价键、同时提高对突变体的选择性。但这也带来新的耐药压力，后面还有 C797S 之类的变化。

课堂活动：分成两组。

一组主张"主要就是空间位阻"，另一组主张"不能只看位阻"。各自从结构图里找证据，再说出一个"光看图无法判断、必须做实验"的点。

## 最后十分钟：看一眼 1YY9

课程三要用这个结构。今天只花十分钟认识一下，不深入。

```pymol
load 1YY9.pdb, 1YY9    # 课程三现场下载；此处仅看一眼，失败时用 course3 的 fallback/inputs/
get_chains 1YY9
```

链是 A、C、D。（不是 A、B、C，很多人会记错。）

- A：EGFR 胞外区，构建体对应 UniProt 25–642
- C：西妥昔单抗 Fab 轻链
- D：西妥昔单抗 Fab 重链

分辨率 2.61 Å。

上色看看：

```pymol
hide everything
show cartoon, 1YY9
color marine, chain A
color palecyan, chain C
color salmon, chain D
```

然后算一下界面：

```pymol
select fab, 1YY9 and (chain C or chain D)
select egfr_contact, 1YY9 and chain A within 4.5 of fab
show sticks, egfr_contact
zoom egfr_contact, 10
```

现在对比一下两个结构的画面：

`1M17` 里，厄洛替尼是嵌在一个凹槽里的。

`1YY9` 里，Fab 是贴在一大片表面上的。

这就是"小分子找口袋"和"蛋白找表位"的区别。课程三要设计的是 mini-protein 结合剂，它面对的是后一种情况。

再强调一遍用词：`egfr_contact` 里的残基叫**接触残基**，是 4.5 Å 这个阈值下的几何事实。**不要叫它们热点**。热点得看"改掉以后结合损失多少"，那是实验问题。这个词用错，答辩会被抓。
