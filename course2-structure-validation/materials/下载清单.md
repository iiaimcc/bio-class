# 课程二数据下载清单

> 课上的序列与结构文件由**学生现场下载**并记录来源；本清单给出 URL、文件名和校验方法。
> `materials/fallback/inputs/` 是同一来源的教师副本，只用于网络失败时兜底。

## 1. 课上需要下载的文件

在 `~/bio-class-course2/` 下执行（浏览器下载也可以，文件名保持一致）：

```bash
# UniProt：EGFR 全长序列
curl -L https://rest.uniprot.org/uniprotkb/P00533.fasta -o EGFR_P00533.fasta

# RCSB PDB：EGFR 激酶域 + 厄洛替尼
curl -L https://files.rcsb.org/download/1M17.pdb -o 1M17.pdb

# AlphaFold DB：EGFR 预测全长结构（版本号以网页 latestVersion 为准）
curl -L https://alphafold.ebi.ac.uk/files/AF-P00533-F1-model_v6.pdb -o AF-P00533-F1-model_v6.pdb
```

网页入口：

- UniProt：<https://www.uniprot.org/uniprotkb/P00533/entry>
- RCSB 1M17：<https://www.rcsb.org/structure/1M17>
- AlphaFold DB P00533：<https://alphafold.ebi.ac.uk/entry/P00533>
- InterPro（任务卡 1.2，不下载文件）：<https://www.ebi.ac.uk/interpro/entry/protein/UniProt/P00533/>

## 2. 记录与校验

下载后立刻记录 **URL、访问日期、`sha256`**，写进 `EGFR_序列档案.md` 的"来源记录"：

```bash
sha256sum EGFR_P00533.fasta 1M17.pdb AF-P00533-F1-model_v6.pdb
```

校验值（与本课包 `fallback/inputs/` 同源，2026-11-02 抓取；文件更新后以自己下载的值为准，并在报告中记录）：

| 文件 | 字节数 | `sha256` |
|---|---:|---|
| `EGFR_P00533.fasta` | 1328 | `684e2da1f3ef05d0ce90d0aefe9125c6f7e9cdcfeac27ae72ed35243b64a73e8` |
| `1M17.pdb` | 252720 | `5b020cd186307d657de80611793554b074f6936a3443d33f81d9b1a58004962e` |
| `AF-P00533-F1-model_v6.pdb` | 772334 | `8b381730ae157a75f2fbc78043aff7b9e605a30420dfe749a56cd61f12125cb9` |

快速检查：

- `grep -c "^ATOM" 1M17.pdb` 应为 2511 条；
- `grep "REMARK   2 RESOLUTION" 1M17.pdb` 应显示 2.60 Å；
- `grep "^HETATM" 1M17.pdb | grep AQ4 | head` 应能查到厄洛替尼（`AQ4`）；
- AlphaFold 文件的 B-factor 列存放 pLDDT（0–100）。

## 3. 兜底

网络不可用、下载超时或文件损坏时：

1. 从 `materials/fallback/inputs/` 取同名文件；
2. 在产出中写明：**用了兜底文件、失败原因、失败时间**；
3. 不得写成"自己现场下载"。兜底文件的来源、抓取日期与校验值见 `fallback/README.md`。
