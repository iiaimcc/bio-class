## 2. PDB 1M17（任务卡 2.1、3、5）

```text
grep "REMARK   2 RESOLUTION" 1M17.pdb   # 2.60 ANGSTROMS
grep "^COMPND" 1M17.pdb                 # 只有一条蛋白链
grep "^HETATM" 1M17.pdb | grep AQ4      # 厄洛替尼，29 个原子
```

| 项目 | 参考值 |
|---|---|
| 方法 / 分辨率 | X-ray / 2.60 Å |
| 蛋白链 | 仅 A 链（EGFR 激酶域构建体） |
| 建模残基范围 | 672–995（312 个残基；PDB 编号） |
| 蛋白原子数 | 2511 |
| 配体 | `AQ4` = erlotinib，29 个原子，`A 999` |
| 水 | 20 个 `HOH` |
| canonical T790 对应 | `chain A / resi 766 / THR`（偏移 = PDB 编号 + 24） |
| T790 与厄洛替尼最近原子距离 | **3.41 Å** |
| 5 Å 口袋残基（PDB 编号，20 个） | 694, 695, 702, 719, 721, 738, 742, 764, 765, 766, 767, 768, 769, 770, 771, 772, 773, 820, 830, 831 |

复算命令（PyMOL）：

```pymol
load 1M17.pdb
select lig, resn AQ4
count_atoms lig                       # 29
select t790, chain A and resi 766 and resn THR
count_atoms t790                      # 7（THR 的 7 个重原子；该残基有 altLoc）
distance d, t790, lig                 # 最近 3.41 Å
select pocket5, byres (chain A and polymer.protein within 5 of lig)
count_atoms pocket5                   # 157
```

> 注意：`within 5 of resn AQ4` 直接写在 `byres(...)` 里时，PyMOL 的选择解析可能把 `resn AQ4` 并入前面的布尔式，导致漏选残基。先 `select lig, resn AQ4`，再 `within 5 of lig`，结果才稳定。

### 任务卡 3 三个视角的验收要点

| 视角 | 应该看到 | 常见错误 |
|---|---|---|
| ① 结构域着色 | 整条 A 链为灰色卡通，激酶域（本结构中就是全部蛋白）为蓝灰色，AQ4 以橙色球棍可见 | 把 `1M17` 当成全长 EGFR，去选 712–979 的“激酶域” |
| ② 口袋表面 | 白色半透明表面包住橙色配体，配体没有被完全遮住 | 表面不透明、配体被埋 |
| ③ T790 标注 | 品红色 T766 侧链 + 标签 `T790 (1M17: T766)`，与配体之间可见距离 | 用 `resi 790`（该结构无此残基）或 `resn ERT` |

```pymol
load AF-P00533-F1-model_v6.pdb

color yellow,  AF-P00533-F1-model_v6 and (b<70 and not b<50)

```

四档 CA 计数（本机复算）：深蓝 573、浅蓝 282、黄 79、橙 276。

> pLDDT 是模型自身的**局部**置信度，不是实验误差，也不能说明配体亲和力或功能状态；结构域之间的相对位置与朝向由 PAE 判读，pLDDT 不能替代它（例如本模型胞外域与激酶域各自分数不错，但两者的相对关系不由此判定）。

## 4. 晶体 vs 预测叠合（任务卡 2.3）

```pymol
align AF-P00533-F1-model_v6 and resi 712-979 and name CA, 1M17 and chain A and polymer.protein and name CA
```

参考输出：

```text
ExecutiveAlign: 268 atoms aligned.
ExecutiveRMS: ... (多轮离群原子剔除)
Executive: RMSD =    0.510 (208 to 208 atoms)
```

- 激酶域折叠高度一致（RMSD ≈ 0.5 Å），说明 AlphaFold 对该段可信；
- 被剔除的离群原子集中在柔性 loop 与末端，不能据此判断“预测比实验更准”；
- 该命令只比较激酶域；全长 EGFR 的胞外域与 C 端尾没有晶体结构可对照。

> 不同 AlphaFold 版本、不同 PyMOL 版本的 RMSD 会有小幅差异（常见 0.5–0.8 Å），报告应记录自己实际运行得到的值。
