# 课程二教案：《靶点确证与结构预测实践》

- 课时：4 学时（1 次课，180 分钟）
- 对象：本科高年级（生物/药学），已完成课程一（或具备转录组基础）
- 场地：云电脑空间（PyMOL、可联网）+ 普通机房（Mol*/AlphaFold DB 网页查看器，备选链路）
- 教学主线：学生把课程一的 EGFR 表达结果转成可审查的蛋白结构证据，并理解结构证据的边界；最后用 1YY9 的胞外抗体界面为课程三的 mini-protein binder 设计建立约束。

---

## 一、教学目标

### 知识目标（K）
  1. 说出靶点确证的证据层次：遗传学 → 表达/蛋白 → 功能（表型）→ 药理学 → 结构，并解释各层的作用与局限；
2. 解释蛋白质结构域（domain）概念，能通过 InterPro/UniProt 注释识别激酶结构域等功能单元；
3. 理解 AlphaFold2 的原理要点：多序列比对共进化、结构模块、置信度指标 pLDDT（残基级）与 PAE（成对距离误差），知道如何用它们判断预测质量；
4. 能区分实验结构（X-ray/EM）与预测结构：分辨率、溶剂/配体、构象状态差异；
5. 理解"可成药口袋"概念与口袋残基在配体结合中的角色，了解常用口袋检测方法。

### 技能目标（S）
1. 能在 UniProt 检索蛋白记录并提取序列、结构域、病理性变异信息；
2. 能从 RCSB PDB 与 AlphaFold DB 下载结构文件（PDB/已验证格式），会读 pLDDT 数值；
3. 能在 PyMOL 中：加载结构、按链/残基/属性着色、显示并调节表面、测量并高亮配体-残基相互作用、标注关键残基、输出出版级截图；
4. 能用 PyMOL 序列视图或脚本快速定位关键残基（如 EGFR 的 T790M、L858R）；
5. 能用网页工具（DoGSiteScorer 或 proteins.plus）做口袋检测并解读结果；
  6. 能把一个自然语言结构问题转成可验证的 PyMOL 脚本，并用对象名、链名、编号和原子数检查 AI 返回的命令。
  7. 备选链路：能用 PDB 网页 Mol* 查看器完成上述可视化的主要任务。

### 素养目标（A）
  1. 形成"任何结构都有质量与来源"的意识——先看 pLDDT/分辨率再解读；
2. 体会多证据整合：结构证据是确证链的一环而非全部；
  3. 养成记录来源（PDB ID、UniProt 登录号）的科研习惯；
  4. 理解 AI 能翻译操作需求，但不能代替结构事实核查。

## 六、教学重点与常见陷阱提示

1. **"预测结构=真实结构"的错觉**：务必演示低置信度区域（pLDDT<70 的 loop），并拿 AlphaFold 结构叠合到晶体结构（PyMOL `align`）让学生看差异；
2. **Don't 让学生逐条输入命令**：PyMOL 脚本化演示（.pml）与 GUI 点选并用——先演示 GUI 一遍，再发脚本兜底；
3. **网络依赖**：PDB/AlphaFold DB 取数是任务卡 1–2 的课堂操作，学生现场下载并记录来源；教师课前抓一份放进 `materials/fallback/inputs/`，网络失败时兜底并标注；
4. **EGFR 的复杂语境**：EGF 受体有胞外域与激酶域；本课用 1M17 讲激酶口袋，用 1YY9 预告胞外表位，避免把两种设计对象混淆；
5. **构象状态**：1M17 是 DFG-in 活性构象，解释"口袋形状取决于构象"。
6. 常见报错与处置见 [docs/故障排查手册.md](../docs/故障排查手册.md)。

## 七、课程间衔接

- 衔接课程一："表达证据 + 结构证据"已经铺好 EGFR 确证链的前两层；
- 预告课程三：结构档案中**结合 EGF 的胞外域构象与界面残基**将成为大分子设计的起点——"你上节课画的界面，就是下节课设计抗体的靶点"；
- 若学生追问突变型（T790M 耐药机制），登记为课程三"复习问题"，教师可在课程三简单呼应（已有抗体 vs 耐药突变的设计考量）。
- 课程三不直接优化 cetuximab，也不把未运行的 RFdiffusion 结果当成事实，而是使用 1YY9 接触区作为新 mini-protein binder 的设计约束。
