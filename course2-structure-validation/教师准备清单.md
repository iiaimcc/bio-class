# 课程二教师准备清单

> 本课把"从数据库取数"设计成课堂操作：学生在课上现场下载 P00533 序列、1M17 与 AlphaFold 模型，并记录来源与校验值。教师课前要做的不是把文件塞进共享目录，而是**自己走一遍完整下载流程**、准备好 `materials/fallback/` 兜底副本，并用学生身份完整走一遍任务卡 1~4。

---

## 一、开课前两周

- [ ] 确认云电脑已装 PyMOL（开源版或教育版）并能**以学生账号**启动（图形界面+命令行均可）；若为教育版，核对许可证可并发数；
- [ ] 确认机房备选链路：`www.rcsb.org`、`alphafold.ebi.ac.uk`、`www.uniprot.org`、`www.ebi.ac.uk/interpro`、`proteins.plus` 均可达（长假后务必实测）；
- [ ] 准备讲义 PPT 需要的真实截图素材（先按下方第二节完成一次现场下载并留档）。

## 二、抓取兜底副本（开课前一周，教师账号执行）

课上由学生现场下载；教师课前用同一套 URL 抓一份放进 `materials/fallback/inputs/`，作为网络失败时的兜底（来源、日期、校验值见 `fallback/README.md`）：

| 文件 | 来源 | 命令/步骤 |
|---|---|---|
| `EGFR_P00533.fasta` | UniProt | 网页 `www.uniprot.org` → 检索 P00533 → Download FASTA，或 `curl -L https://rest.uniprot.org/uniprotkb/P00533.fasta -o EGFR_P00533.fasta` |
| `1M17.pdb` | RCSB | 网页 PDB ID 1M17 → Download Files → PDB，或 `curl -L https://files.rcsb.org/download/1M17.pdb -o 1M17.pdb` |
| `AF-P00533-F1-model_v6.pdb` | AlphaFold DB | 网页 `alphafold.ebi.ac.uk/entry/P00533` → Download PDB，或 `curl -L https://alphafold.ebi.ac.uk/files/AF-P00533-F1-model_v6.pdb -o AF-P00533-F1-model_v6.pdb` |

> 版本核对：官方 `1M17.pdb` 中厄洛替尼的三字母残基名是 `AQ4`；canonical T790 对应该结构 A 链 T766。AlphaFold DB 的版本号会更新（v4 已不再提供下载），以 `https://alphafold.ebi.ac.uk/api/prediction/P00533` 返回的 `latestVersion` 为准；换版本后同步更新 `fallback/README.md` 与 `fallback/expected/结构事实参考.md`。

## 三、开课前一周（用学生账号完整演练）

- [ ] **用学生账号**逐条完成任务卡 1~4（不要用管理员账号，权限差异会导致"老师行学生不行"）：
  - 任务卡 1：UniProt/InterPro 页面可用，学生能现场下载 FASTA 并核对 `sha256`；
  - 任务卡 2：学生能现场下载 1M17 与 AlphaFold 模型，PyMOL 能加载（注意中文路径与文件名空格）；
  - 任务卡 3：三个指定视角能截出图（`png xxx.png, dpi=300` 正常写盘）;
  - 任务卡 4：DoGSiteScorer 上传 `.pdb` 成功出结果（该站上传速度不稳定，备用方案：proteins.plus 主页改名/改版时使用 `fpocket` 本地版或 `PrankWeb` 网页，教师提前选定一个兜底站）；
- [ ] 额外完成任务卡 5：用浏览器 AI 生成 `student_view.pml`，故意准备一份使用 `resn ERT` 和 `resi 790` 的错误答案，演示学生用 RCSB、残基名和 `count_atoms` 找错；
- [ ] 从课程三 `../course3-macro-drug-design/materials/fallback/inputs/1YY9.pdb` 读取真实结构（不要复制第二份），核对蛋白链 A=EGFR、C=Fab light、D=Fab heavy（B/E/F/G 是糖链），并准备 4.5 Å 接触区截图；
- [ ] 记录学生机器上每个任务卡的实际耗时（用于微调时间轴）；
- [ ] 预渲染"标准答案图"三张（任务卡 3 的成品视角），上课时投影展示，防止学生"不知道长啥样算对"；
- [ ] 准备 `ai_pymol_review.md` 参考答案：记录对象名、A 链、`AQ4`、canonical T790→1M17 T766 的来源和 `count_atoms` 结果；
- [ ] 截取 P11/P13/P15/P22/P25 所需的真实运行图放入 PPT。

## 七、教师参考答案要点（任务卡验收基准）

| 检查点 | 预期 |
|---|---|
| 任务卡1 结构域表 | 激酶域 709–968（PKinase_Tyr）；致病突变 ≥3 条（L858R、T790M、G719S、exon19 del 等）；每条有来源 |
| 任务卡2 RMSD | 按手册的 `align ... resi 712-979` 命令，发布版（AF v6 + PyMOL 3.x）实测 RMSD = 0.51 Å（208 个 CA，自动剔除 60 个离群原子后）；不同 AlphaFold 版本会有差异，不要求学生凑固定值 |
| 任务卡2 pLDDT | 不要求学生杜撰均值；应记录局部高/低置信区域，并说明 pLDDT 不代表配体亲和力 |
| 任务卡3 视角② | AQ4 被激酶口袋表面部分包围；图中 T790 标为 `T790 (1M17: T766)` |
| 任务卡5 AI 脚本 | `AQ4`、T766/THR、5 Å邻域选择非空；学生能指出 `ERT`/`resi 790` 错误并留下来源和验证输出 |
| 任务卡4 口袋 | top口袋应与 AQ4 所在 ATP 位点空间重合；分数只作工具输出记录，不设“≥0.7即证明可成药”的硬阈值 |
| 讨论题 4.2 | 至少提到局部几何、ATP竞争和构象；三代药可讨论C797共价策略，但不能写成“避开位阻即可” |

## 八、课程三衔接材料

课程三使用同一个 EGFR，但设计对象变为胞外 domain III 的 mini-protein binder。教师不应把 1M17 的胞内激酶口袋直接交给课程三。

- 共享结构：`../course3-macro-drug-design/materials/fallback/inputs/1YY9.pdb`（课程三同样由学生现场下载，此文件为兜底副本）；
- 真实链：A=EGFR 胞外域，C=Fab light chain，D=Fab heavy chain；
- 教师用 PyMOL 计算并展示 4.5 Å 接触区：EGFR 侧重点为 A349、A353、A382/A384、A408–A418、A438–A443、A465–A473；
- 课堂只把它们称为“接触残基/表位候选”，不要称为已证实热点；热点需要进一步实验或能量证据。

> 注意：结构范围、RMSD、口袋分数和接触数量必须以教师本学期实际材料与运行结果为准。参考答案用于核对对象和解释方向，不要求学生凑固定数字。
