## 任务卡 1：序列层面的确证（25 分钟）

### 1.1 用 UniProt 建立序列档案（网页，10 分钟）
打开浏览器 → `www.uniprot.org` → 搜索框输入 `P00533` →

- 记录：功能一句话（"receptor tyrosine kinase ..."）；
- 进入 **Feature viewer**（功能注释标签），截图"结构域"区域；
- 找到 **Sequence** 页，点 **Download FASTA**，保存为 `EGFR_P00533.fasta`（也可用命令）：
  ```bash
  curl -L https://rest.uniprot.org/uniprotkb/P00533.fasta -o EGFR_P00533.fasta
  sha256sum EGFR_P00533.fasta      # 与 materials/下载清单.md 核对
  ```
- 找到 **Pathological variants** / 提及的致病突变，记录 ≥ 3 个（如 L858R、T790M、G719S）。

> 卡住了？UniProt 界面每年改版：找不到 Pathological variants 就搜关键词 "Pathogenic"；格式参照本课 `课堂讲义.md` 的来源记录示例，不要凭记忆补写编号。

### 1.2 用 InterPro 做结构域注释（5 分钟）
打开 `www.ebi.ac.uk/interpro` → 搜索 `P00533` → 记录以下信息：

| 结构域/家族 | 名称 | 起始残基–终止残基 | 数据库 |
|---|---|---|---|
| （示例格） | Receptor L-domain | 57–178 | InterPro |
| | PKinase_Tyr（激酶域） | 709–968 | | 
| | | | |

> **为什么重要**：激酶域 709–968 是药物（如厄洛替尼）结合的地方——课程三的重点是把 EGFR **胞外域**（西妥昔单抗的靶区）与这个激酶域区分开：小分子抑制胞内激酶活性，抗体阻断胞外配体结合。

### 1.3 写出序列档案（10 分钟）
新建 `EGFR_序列档案.md`，内容：登录号、物种、长度（1210 aa）、结构域表、致病突变表，以及来源记录（UniProt 版本、PDB 条目）。再画一条“胞外域—跨膜—胞内激酶域”的架构线，并在图上标出 1M17 和 1YY9 分别对应哪一段。

**必须写下的边界**：序列注释支持“这条链有哪些功能区域”，不能单独支持“EGFR 在本样本中是致病原因”。

## 任务卡 2：实验结构与 AlphaFold（30 分钟）

### 2.1 下载并打开晶体结构（5 分钟）
先下载，再在 PyMOL 里打开（`File→Open` 选择 `~/bio-class-course2/1M17.pdb`，或在 PyMOL 命令行 `load 1M17.pdb`）：

```bash
curl -L https://files.rcsb.org/download/1M17.pdb -o 1M17.pdb
sha256sum 1M17.pdb
```

也可以在 RCSB 页面 `www.rcsb.org/structure/1M17` → Download Files → PDB 下载。

**检查**：右侧 Object 列表出现 `1M17`；`show cartoon`；`spectrum` 那类着色先不着急——现在回答：

- 分子里有什么？（蛋白质链、厄洛替尼、水分子和其他非蛋白组分？）
- 官方 `1M17.pdb` 中厄洛替尼的三字母残基名是 `AQ4`。运行：`select erlotinib, 1M17 and resn AQ4`，再用 `count_atoms erlotinib` 检查选择非空。

> 卡住了？先输入 `show sticks, organic` 查看所有有机组分，再到 RCSB 1M17 的 Chemical Components 或 PDB `HETNAM` 核对。药物名称 erlotinib、课堂简称 ERT 和文件中的 `resn AQ4` 不是一回事。

### 2.2 下载并打开 AlphaFold 预测结构（5 分钟）
在 `alphafold.ebi.ac.uk/entry/P00533` 点 **Download PDB**，或：

```bash
curl -L https://alphafold.ebi.ac.uk/files/AF-P00533-F1-model_v6.pdb -o AF-P00533-F1-model_v6.pdb
```

然后在 PyMOL 中 `load AF-P00533-F1-model_v6.pdb`。AlphaFold DB 会更新版本；以页面显示的 `latestVersion` 为准，不要照抄旧文件名。

**pLDDT 判读（6 分钟）**：在序列视图（Display → Sequence）看每个残基；或更简单：命令行
```
spectrum b, blue_white_red, AF-P00533-F1-model_v6, minimum=0, maximum=100
```
- 蓝色 = 高置信度（pLDDT > 90），红/黄 = 低置信度；
- **记录**：激酶域（709-968）的置信度如何？N 端信号肽与胞外部分置信度如何？低置信度往往意味着"柔性/无序/多构象"。

> 提示：AlphaFold DB 页面（`alphafold.ebi.ac.uk/entry/P00533`）有官方 pLDDT 着色与"Predicted Aligned Error"图——打开它对照你的 PyMOL 观察。

### 2.3 质量对比（13 分钟）
把两个结构 **叠合** 看差异：

```
align AF-P00533-F1-model_v6 and resi 712-979 and name CA, 1M17 and chain A and polymer.protein and name CA
```

- 记录 RMSD（输出里 `RMSD = X.XXX`）；参考值：AF v6 + PyMOL 3.x 实测约 **0.51 Å（208 个 CA）**，不同 AF 版本会有差异，不要凑固定值；
- 观察：激酶域折叠一致吗？Loop 区差异大吗？（旋转比较）
- **填写结构质量记录**：

| 结构 | PDB ID/来源 | 质量指标 | 我的结论（可信度） |
|---|---|---|---|
| 晶体结构 | 1M17，X-ray | 2.6 Å | 激酶域可信；无全长 |
| 预测结构 | AF-P00533 | 激酶域局部 pLDDT/PAE 观察 | 写清可信区域与不能解释的区域 |

## 任务卡 3：PyMOL 可视化：三个指定视角（35 分钟）

> 参照教师的演示一步步做，做完一张截一张（`png 视角名.png, dpi=300`）。三个视角是提交的硬指标。

### 视角① 结构域着色图
1M17 本身就是激酶域构建体。不要把 UniProt canonical 712–979 直接当成 PDB 编号；在 1M17 中直接选择蛋白链：

```
color grey80, 1M17

color slate, kinase
```
截图为斜 45° 前视图，配体可见为球棍。

### 视角② 口袋表面图（配体视角）
```
hide everything
show cartoon, 1M17
select erlotinib, 1M17 and resn AQ4
select pocket6, byres ((1M17 and chain A and polymer.protein) within 6 of erlotinib)
show surface, pocket6
color white, pocket6
show sticks, erlotinib
color orange, erlotinib
```
你可以得到"口袋里躺着配体"的俯视图；旋转到配体被表面半包裹的视角截图。

### 视角③ 关键残基标注图
```
select t790, 1M17 and chain A and resi 766 and resn THR
show sticks, t790

label t790 and name CA, "T790 (1M17: T766)"

```
对于距离判断——提问第 4 步会用：**T790 与配体（厄洛替尼）的距离多远？**

> 卡住了？①label 不显示：`set label_color, black` 再 `set label_size, 40`。②表面把配体全盖住：`set transparency, 0.5`。

### 进阶（选做）：突变体对比

## 任务卡 5：让 AI 协助写 PyMOL 脚本，但由你核验事实（30 分钟）

这不是把作业交给 AI。你的任务是把一个明确的结构问题翻译成脚本，再检查 AI 有没有猜错对象、链和编号。

### 5.1 先写需求，再问 AI（5 分钟）

在 `ai_pymol_review.md` 中先填写：

```text
当前对象名：1M17
结构来源：PDB 1M17
目标：突出 erlotinib、其 5 Å 内的蛋白残基，以及 canonical T790
希望输出：sticks、标签、PNG 图片
已核对事实：erlotinib 的 resn 是 AQ4；canonical T790 对应 1M17 chain A / resi 766 / resn THR
必须验证：selection 原子数、链名、配体 resn、canonical/PDB 编号映射
```

将下列提示词复制给你使用的 AI 工具，并把返回内容保存下来：

```text
我在 PyMOL 中加载了官方 PDB 1M17，对象名是 1M17。
已核对：蛋白链为 A；erlotinib 的 resn 是 AQ4；canonical EGFR T790 对应 1M17 的 chain A / resi 766 / resn THR。
请生成一个 .pml 脚本：显示 erlotinib、配体 5 Å 内的完整蛋白残基和 T790；添加标签和 PNG 输出。
脚本必须分别建立 erlotinib、pocket5、t790 三个选择并执行 count_atoms。
不要自行更改链号、配体名或编号。
```

### 5.2 人工审查与运行（15 分钟）

把 AI 返回脚本保存为 `student_view.pml`，逐行检查后在 PyMOL 运行。至少执行：

```pymol
get_chains 1M17
select erlotinib, 1M17 and resn AQ4
count_atoms erlotinib
select t790, 1M17 and chain A and resi 766 and resn THR
count_atoms t790
select pocket5, byres ((1M17 and chain A and polymer.protein) within 5 of erlotinib)
count_atoms pocket5
```

如果 `t790` 或 `erlotinib` 是 0，不能继续截图，先回到 PDB 文件、RCSB Chemical Components 和编号映射核对。若 AI 写成 `resn ERT` 或 `resi 790`，必须在 `ai_pymol_review.md` 记录错误原因、事实来源、人工修正和修正后的原子数。

### 5.3 用结果审查 AI（10 分钟）

在 `ai_pymol_review.md` 完成表格：

| 检查项 | AI 原文 | 我是否接受 | 证据/修改 |
|---|---|---|---|
| 对象名 | | | Object 面板 |
| 链名 | | | `get_chains` 输出 |
| erlotinib / AQ4 | | | RCSB Chemical Components/PDB |
| T790 → T766 映射 | | | UniProt 与 PDB 对照 |
| 选择数量 | | | `count_atoms` |
| 图片是否回答问题 | | | 截图 |

提交 `student_view.pml` 和 `ai_pymol_review.md`。AI 只能帮助写命令，不能替你填写残基事实，也不能替你写确证结论。
