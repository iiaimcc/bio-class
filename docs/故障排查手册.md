# 故障排查手册

> 按"现象 → 原因 → 处置"组织。课前教师逐条走查，课上出现问题按本章快速定位。每学期末更新一次（教师在教学后把新问题写进各课教师准备清单并同步到本章）。

## 0. 通用层

### 0.1 学生登录不了云电脑
- 原因：账号未创建/密码错误/并发数满/浏览器缓存。
- 处置：①验证教师账号可登录（区分"平台问题"与"账号问题"）；②重置该账号密码；③并发满时 5 分钟内重试或联系云服务商扩容；④换无痕窗口重试一次，排除缓存。

### 0.2 网络不通/白名单站点打不开
- 处置：先 `ping` 或浏览器直接访问 `www.baidu.com` 判断总出口；再试白名单域名（它们在校内网络策略中经常被误拦，需管理员放行或报异常）。

### 0.3 学生文件丢失（作业前）
- 处置：课前向学生重申"产出必须本地另存 + 学号命名"；共享目录每日归档一次（教师脚本 5 分钟任务）。

## 1. 课程一（R/RStudio）

| 现象 | 原因 | 处置 |
|---|---|---|
| 控制台报 `There is no package called 'DESeq2'` | 学生环境未装包 | `BiocManager::install("DESeq2")`；若 BiocManager 无，先 `install.packages("BiocManager")`；带全班装一轮（教师广播或共享 R 库路径，见 env 指南附录 A） |
| `49: In ... failed to converge` 警告（DESeq2 拟合） | 部分基因低计数/零计数 | 属正常警告，不影响课程结论；向学生解释"个别基因拟合差"即可 |
| `all(colnames(counts) == meta$sample_id)` 报错 | 表列顺序不匹配 | 重新 `read.csv` 两表；检查 `sample_meta.csv` 是否被改动（课堂上有人覆盖过？恢复共享副本） |
| 火山图全是灰点 | 分组写反（Tumor/Normal 反了） | 检查 meta 的 condition 列与脚本 `contrast` 行；对照参考答案 |
| `colSums` 数值完全一样 | 学生读错文件（如读入基因注释列） | 让其检查 `str(counts)` 结构与表头 |
| RStudio 卡死 | 内存不足 | 重启会话；确认没跑 60660×30 之外的大变形（课程一 counts 约 6 MB，正常不会卡） |
| 第 0 步下载慢/中断 | 机房出口拥塞或超时 | 脚本会重试并核对 md5，重跑即续传（`--cache` 复用）；整班改用共享只读缓存 `--cache /共享目录/gdc_cache`；仍不行走 `materials/fallback/inputs/` |
| 下载后 md5 校验失败 | 网络截断/代理回包 | 脚本自动丢弃 `.part` 重试；连续失败改用兜底副本，并在报告里注明来源 |
| `api.gdc.cancer.gov` 不可达 | 网络策略拦截 | 机房链路的网页备选：`portal.gdc.cancer.gov` 手动加购下载；或兜底副本 |
| `target_shortlist.csv` 里找不到 EGFR | 学生误以为脚本出错 | 这是设计好的教学点：EGFR 表达不显著，靠突变进入候选，见《课堂讲义》"EGFR 为什么不在 shortlist 里" |
| 四层漏斗里 RET/ROS1 被砍，学生觉得不合理 | 学生只看"有没有获批药" | 获批药针对的是**融合**，本队列是点突变（T350N、E901K、I1374F）；药和变异类型必须对得上，见《课堂讲义》"四层证据叠起来" |
| `integrated_candidates.csv` 报错找不到 | 缺 `driver_annotation.csv` | 该文件在 `data/`，确认第一个参数指向数据目录（仓库内为 `../data`）；兜底副本里也带这份 |

## 2. 课程二（PyMOL/结构）

| 现象 | 原因 | 处置 |
|---|---|---|
| `load` 后屏幕空白 | 视角/显示层设置问题（color/eye） | `zoom`；`show cartoon`；`reset` |
| 配体不显示 | 配体名非 ERT 或选了 chains-only | `select organic` + `show sticks` 兜底 |
| `align` RMSD 巨大（>5 Å） | 链/残基范围不对 | 限定激酶域（`and resi 709-968`）再对齐 |
| label 不显示 | label 颜色=白色（白底）或 size 小 | `set label_color, black` + `set label_size, 40` |
| `png` 报错 | 输出目录不可写 | 给出绝对路径（`/home/.../shot.png`） |
| 教育版 PyMOL 弹许可错误 | 许可证服务器未激活/网络不通 | 课前教师解决；课上学生改用开源版或教师演示补充 |

## 3. 课程三（RFdiffusion/ProteinMPNN/回折/PyMOL）

### 3.1 在线 backbone 生成

| 现象 | 原因 | 处置 |
|---|---|---|
| Colab 无 GPU/一直排队 | 免费运行时配额、时段或网络不稳定 | 学生使用教师同参数预生成 backbone，报告标明“教师预生成”；不要伪造运行链接 |
| 目标 PDB 上传失败 | 文件太大、格式异常或链/残基记录不完整 | 使用教师整理的目标局部 PDB；先在 PyMOL 打开并记录链名 |
| 生成的 backbone 远离表位 | 表位约束未正确输入、长度/目标链设置错误 | 回到设计规格，核对目标链 A、表位残基和长度；保留该候选作为失败对照 |
| backbone 穿入 EGFR/出现严重碰撞 | 生成样本不合格 | 淘汰并记录原因，不要为了“有输出”强行进入序列设计 |

### 3.2 ProteinMPNN 与回折

| 现象 | 原因 | 处置 |
|---|---|---|
| ProteinMPNN 输出为空 | 输入 PDB 链记录或设计链设置不完整 | 核对设计链/固定链；使用教师 quick demo 和预生成序列兜底 |
| 只得到一条序列 | 采样数设置过低或下载不完整 | 记录实际输出；使用教师同参数序列表，不把一条序列写成充分筛选 |
| 把设计分数写成 KD | 概念混淆 | 改写：分数是序列对骨架的适配指标；KD 必须用 SPR/BLI 等实验测定 |
| 回折结构脱离表位 | 序列没有保持设计骨架、复合物采样不稳定或表位约束不足 | 比较多条序列和多个预测；淘汰该候选并写入 `refold_review.md` |
| ColabFold/在线 Boltz 不可用 | 网络、配额或服务变更 | 使用教师回折结构；报告写明工具未实际运行，禁止把预生成结果冒充现场结果 |

### 3.3 本地 Boltz（可选复核）

| 现象 | 原因 | 处置 |
|---|---|---|
| `No CUDA capable device` | 云电脑 GPU 驱动未装/未激活 | 使用在线回折或教师预生成结果；不要让全班等待 CPU 预测 |
| MSA server timeout | 外网受限 | 使用教师已验证的离线参数或共享结果，并记录实际 MSA 模式 |
| YAML 语法错 | 缩进、占位序列或链映射错误 | 核对 `version: 1` 和三段 protein；1YY9 参考链是 A/C/D；不要保留 `<...>` 占位符 |
| 结果与 1YY9 差异大 | 输入序列、链映射或结构范围不一致 | 记录 Boltz ID 与 PDB A/C/D 的映射；只在公共 EGFR 区域比较 |

### 3.4 PyMOL 界面分析

| 现象 | 原因 | 处置 |
|---|---|---|
| `chain B` 选中为空 | 1YY9 真实链是 A=EGFR、C=Fab light、D=Fab heavy | 先运行 `get_chains 1YY9`；按 A/C/D 修正脚本 |
| `within 4.5 of` 报语法错 | 选择语句括号不对 | 1YY9 使用 `(chain C or chain D) and within 4.5 of chain A`；预测结构先确认实际链名 |
| CDR 着色位置不对 | CDR 区间编号与 PDB 编号有偏移 | 以 `CDR标注表.md` 教师预填的 PDB `resi` 为准，不要直接用 IMGT 编号 |
| 接触残基列表导出为空 | 抗体-抗原距离 >4.5 Å（预测或原始结构） | 换距离阈值 6.0 Å 再试；或检查是否选对了链 |
| `png` 报错 | 输出目录不可写 | 用绝对路径（`/home/.../界面.png`） |

### 3.5 网页/序列标注（abYsis/IMGT）

| 现象 | 处置 |
|---|---|
| abYsis/IMGT 打不开或响应慢 | 属于外网不稳定；教师已预填 `CDR标注表.md`，学生直接用教师版本，不现场强刷 |
| 从 RCSB 下载 1YY9 超时 | 教师课前下载好发给学生；课上只读本地文件 |
| UniProt FASTA 下载失败 | 教师课前下载 P00533 分发；或直接用 `EGFR_cetuximab_序列.md` 教师已填版本 |

## 4. 备选链路（网页工具）

| 现象 | 处置 |
|---|---|
| GEPIA2/Enrichr 打不开 | 确认学校网络可访问国际站；换浏览器（Chrome/Edge）；由教师统一截图讲解 |
| proteins.plus 上传卡住 | 换用备用口袋检测（PrankWeb 或本地 fpocket）；或者用共享的教师检测结果 |
| Mol* 查看器空白 | 浏览器版本过旧；升级或换 Chrome |

## 5. 时间失控与流程兜底

| 情形 | 预案 |
|---|---|
| 某任务卡整体超时 10 分钟 | 裁掉下一个选做任务；用教师预生成结果演示并让学生"解读+截图"（不扣分） |
| 全班某环节全挂（如在线设计服务不可用） | 当场切换为“教师同参数预生成结果 + 学生结构审查”，提交中明确来源；课后补跑在线环节 |
| 学生机器不足 | 2 人 1 机，考核不变（组队本来就允许 2 人） |
| 学生提前完成 | 给选做任务卡（各课都有），完成者加分 |
