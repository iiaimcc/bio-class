# 文献依据：每一步结论的出处

这份文件回答一个问题：**课上的每一条结论，凭什么这么说？**

教学里有两条硬规则：

1. 任何一条超出"本机脚本跑出来的数字"的陈述，都要能落到一条公开文献或一个公开数据库条目上；
2. 引用必须逐条核对（PMID 能打开、标题对得上）。**AI 生成的文献列表默认不可信**——编造 PMID 是当前大模型最常见的错误之一，本课把它当作一个必查环节（见第 5 节）。

文中 `PMID` 均为 Europe PMC 实检通过（2026-11-03 核对）；预印本给 DOI。

---

## 1. 候选为什么最终落在 EGFR：判据，不是内定

课程一说"数据选出候选"，但**候选能不能进课程二、三，还要过一道可验证性检查**。理由很实际：只有 4 学时的一门课，要让学生走完"结构 → 表位 → 设计 → 复核"，选中的靶点必须在每一步都能找到公开、可复算的材料。判据是四问：

| 四问 | 为什么必须问 |
|---|---|
| ① 蛋白露在细胞表面吗？ | 课程三设计的是 mini-protein/抗体类大分子，进不了细胞膜；胞内靶点走不了这条路线 |
| ② 有公开的实验结构吗？ | 课程二要学生自己叠合、量口袋/表位距离，只有预测模型时无法验证"实验事实" |
| ③ 有获批或临床阶段的药吗？ | 没有先例，学生无法判断"什么样的结合才算有用" |
| ④ 每一课都有可引文献吗？ | 学生的每条结论都要有出处，否则课堂只能停在"我觉得" |

把课程一突变层的 9 个候选逐项过一遍（结构查 RCSB，定位查 `driver_annotation.csv` 与 UniProt，药物状态查文献）：

| 候选 | 表面 | 公开结构 | 有药 | 课程三路线可行 | 卡在哪 |
|---|---|---|---|---|---|
| **EGFR** | 是（受体酪氨酸激酶，胞外 domain I–IV） | 1IVO（配体结合）、1M17/4HJO（激酶域+抑制剂）、1YY9（西妥昔单抗复合物） | 是（吉非替尼、厄洛替尼、奥希替尼、西妥昔单抗） | **可行** | 无 |
| KRAS | 否（胞内膜结合） | 有（如 4OBE 等） | 是（G12C 抑制剂） | 不可行 | 大分子够不着，只能做小分子 |
| TP53 | 否（核内转录因子） | 有 | 基本没有（多数突变是功能缺失） | 不可行 | 无口袋可打，属"恢复功能"难题 |
| STK11 / KEAP1 | 否 | 有 | 无 | 不可行 | 抑癌基因缺失，不是"抑制"对象 |
| SMARCA4 | 否（核内染色质重塑） | 有 | 临床阶段有限 | 不可行 | 胞内、表位不适用 |
| PIK3CA | 否（胞内激酶） | 有 | 是（PI3K 抑制剂） | 不可行 | 胞内；本队列为 H1047R 类点突变 |
| RET / ROS1 | 是 | 有 | 是，但**针对融合** | 部分可行 | 本队列是点突变（RET p.T350N、ROS1 p.I1374F），药与变异类型对不上 |

结论：**9 个候选里只有 EGFR 四问全过。** 这不是"教师内定 EGFR 再补理由"，而是任意一个学生按这张表查一遍都会得到同一结果——这正是课上要学生自己动手做的一步（实操手册第 4 步）。

### 那表达层 top 的候选呢

表达层 top（TERT、HTR3A、TOP2A、CDKN2A、SLC6A3）不是差候选，但它们和本课程三的路线不匹配：

- TOP2A 是**核内**拓扑异构酶，已上市药是依托泊苷/拓扑替康这类**细胞毒化疗药**（小分子、无表位概念）；
- CDKN2A、CCNE1 属细胞周期调控，同样在胞内；
- 它们要确证还依赖"敲除/RNAi 依赖实验"，本课没有这个环节。

所以表达层候选的结局是：**进候选池、写进报告、作为后续依赖实验的对象**，而不是被丢掉。课程二、三选择 EGFR，是因为它在本课的四问下唯一可验证——这一点必须在课上讲明，否则学生会以为"排名第一的就是最好的靶点"。

## 2. 课程一：每个环节的出处

| 课程环节 | 结论 | 依据 |
|---|---|---|
| 数据来源 | 真实 TCGA-LUAD 表达与突变来自 NCI GDC 公开层 | Collisson et al., *Nature* 2014（TCGA LUAD 主论文，PMID 25079552）；GDC 数据门户 `portal.gdc.cancer.gov` |
| 差异分析 | 用负二项模型 + 收缩估计得到 log2FC 与 padj | Love et al., *Genome Biol* 2014（DESeq2，PMID 25516281） |
| 通路富集 | GO BP 用 `clusterProfiler`；第二条通路库用 Reactome（离线注释） | Yu et al., *OMICS* 2012（clusterProfiler，PMID 22455463）；Yu & He, *Mol Biosyst* 2016（ReactomePA，PMID 26661513） |
| EGFR 在 LUAD 是驱动基因 | EGFR 激活突变（19del、L858R）预测 TKI 敏感性 | Lynch et al., *N Engl J Med* 2004（PMID 15118073）；Paez et al., *Science* 2004（PMID 15118125）；综述 Sharma et al., *Nat Rev Cancer* 2007（PMID 17318210） |
| 突变阳性 ≠ mRNA 升高 | 肿瘤可依赖单一激活的癌基因而不改变其转录本丰度（"癌基因成瘾"） | Weinstein, *Science* 2002（PMID 12098689）；Sharma & Settleman, *Genes Dev* 2007（PMID 18079171） |
| EGFR 有获批药 | 厄洛替尼在经治 NSCLC 生存获益；奥希替尼用于 T790M 耐药 | Shepherd et al., *N Engl J Med* 2005（PMID 16014882）；Jänne et al., *N Engl J Med* 2015（PMID 25923549） |
| 耐药机制 | T790M 二次突变导致一代 TKI 耐药 | Pao et al., *PLoS Med* 2005（PMID 15737014） |
| EGFR 信号网络 | EGFR 属 ERBB 家族受体酪氨酸激酶，需配体诱导二聚 | Yarden & Sliwkowski, *Nat Rev Mol Cell Biol* 2001（PMID 11252954） |

> 注意口径：上表第 4 行说的是"EGFR 突变是驱动事件"，**不是**"EGFR 在肺癌里高表达"。本队列实测 EGFR mRNA 无显著差异（log2FC −0.206、padj 0.564），这是数据事实，与文献不冲突——两者回答的是不同问题。

## 3. 课程二：结构证据的出处

| 环节 | 结论 | 依据 |
|---|---|---|
| 胞外域构象 | EGFR 胞外 domain I–IV 与 EGF 结合的晶体结构 | Ogiso et al., *Cell* 2002（PDB 1IVO，PMID 12297050） |
| 激酶域与抑制剂 | 4-苯胺喹唑啉（厄洛替尼骨架）结合在 ATP 口袋 | Stamos et al., *J Biol Chem* 2002（PDB 1M17，PMID 12196540） |
| 西妥昔单抗表位 | 西妥昔单抗结合 domain III，直接阻断配体结合 | Li et al., *Cancer Cell* 2005（PDB 1YY9，PMID 15837620） |
| 二聚化界面 | 胞外—跨膜区界面与激酶激活的"松散偶联" | Lu et al., *Mol Cell Biol* 2010（PDB 3NJP） |
| 结构预测 | AlphaFold2 给出 per-residue pLDDT，可作置信度判读 | Jumper et al., *Nature* 2021（PMID 34265844） |
| 预测模型来源 | AlphaFold DB 提供 UniProt 全序列模型（本课用 P00533 v6） | Varadi et al., *Nucleic Acids Res* 2024（PMID 37933859） |

课程二的一条纪律由此而来：**实验结构（1M17/1IVO/1YY9）与预测模型（AF v6）必须分开标注**，不能混着用——前者是"测出来的事实"，后者是"算出来的估计"，判断口袋与表位时只能以前者为准。

## 4. 课程三：设计与复核的出处

| 环节 | 结论 | 依据 |
|---|---|---|
| CDR 编号 | 抗体可变域按 IMGT 规则编号，CDR 边界固定 | Lefranc et al., *Dev Comp Immunol* 2003（PMID 12477501）；Dunbar & Deane, *Bioinformatics* 2016（ANARCI，PMID 26424857） |
| 骨架生成 | RFdiffusion 用扩散模型生成指定表位上的蛋白骨架 | Watson et al., *Nature* 2023（PMID 37433327） |
| 序列设计 | ProteinMPNN 在固定骨架上设计序列 | Dauparas et al., *Science* 2022（PMID 36108050） |
| 复合物预测 | Boltz-1 预测蛋白—蛋白复合物并给出 ipTM/pAE | Wohlwend et al., bioRxiv 2024, DOI `10.1101/2024.11.19.624167`（预印本，未同行评议） |
| 复合物预测（对照） | AlphaFold3 的同类能力与指标定义 | Abramson et al., *Nature* 2024（PMID 38718835） |
| 表位选择的现实约束 | 已知抗体（西妥昔单抗）占据 domain III，可作竞争性设计的参照 | Li et al., *Cancer Cell* 2005（PMID 15837620） |

课程三必须对学生说明的边界：**RFdiffusion/ProteinMPNN/Boltz 都是方法学论文里的通用能力，公开文献中并没有"针对 EGFR 的 de novo mini-protein 药物"**。所以课程三的产物是"可复核的设计练习 + 一份说明它离药还有多远的方案书"，不是"做出了一个 EGFR 新药"。

## 5. 引用纪律（学生必读，教师必查）

1. **每条结论后面写 `(PMID xxxxx)` 或 `(PDB xxxx)`**；数据库条目给登录号，不给网址截图。
2. **查不到的文献不许写。** AI 助手给的引用必须逐条打开核对：标题、期刊、年份、结论是否真的支持你写的那句话。
3. 核对方式（任选其一）：
   - Europe PMC：`https://europepmc.org/article/MED/<PMID>`，能打开且标题一致才算过；
   - 命令行：`curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<PMID>&format=json"`；
   - 结构：`https://www.rcsb.org/structure/<PDB ID>`，核对分辨率、配体、链组成。
4. 引用一条**不支持**你结论的文献，比不引用更糟——报告的"参考文献"一栏按此判分（见《考核方案》）。
5. 预印本（如 Boltz-1）必须标注 `preprint`，不能当成已发表证据使用。
