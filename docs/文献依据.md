# 文献依据：每一步结论的出处

这份文件回答一个问题：**课上的每一条结论，凭什么这么说？**

教学里有两条硬规则：

1. 任何一条超出"本机脚本跑出来的数字"的陈述，都要能落到一条公开文献或一个公开数据库条目上；
2. 引用必须逐条核对（PMID 能打开、标题对得上）。**AI 生成的文献列表默认不可信**——编造 PMID 是当前大模型最常见的错误之一，本课把它当作一个必查环节（见第 5 节）。

文中 `PMID` 均为 Europe PMC 实检通过（2026-11-03 核对）；预印本给 DOI。

## 1. 候选怎么定的：判据只放肿瘤与分子的事实

先立两条禁令，它们是这一课最容易犯、也最隐蔽的错：

- **禁令一："有没有已经上市的药"不能当筛选条件。** 这是拿已知答案反推过程：EGFR 之所以有名，恰恰因为已经有药；用它做筛子，等于把结论当证据，而且会把所有还没有药的新靶点全部刷掉——按这个标准，任何新靶点都不配做靶点。
- **禁令二："能不能查到文献"也不能。** 文献多少取决于这个靶点出名多久，与它是不是好靶点无关；而且文献是**后验**的——研究还没做，哪来的文献。

漏斗里只放三类事实，它们都是肿瘤或分子自身的属性：

| 判据 | 来源 | 回答什么 |
|---|---|---|
| ① 本队列有非沉默突变吗？ | `mutation_matrix.csv`（GDC MAF） | 这个基因在病人身上真的被打坏了吗 |
| ② 变异把蛋白"打开"还是"关掉"？ | 截短变异由 MAF 的 `variant_class` 自动判定；错义/框内变异由学生查 ClinVar / CIViC 后填 `variant_calls.csv` | 我们要**抑制**它，所以需要功能获得；功能缺失要的是恢复功能，意义未明只能标未知 |
| ③ 蛋白在我们要设计的那种药够得着的地方吗？ | `target_context.csv`（`annotate_targets.py` 查询 UniProt 自动生成：`has_extracellular_domain`） | 课程三做的是大分子（进不了细胞膜）。这是**我们对模态的选择**，不是靶点的优劣——换小分子，胞内蛋白反而合适 |

三层的判定方式刻意分成三种，本身就是教学内容：

| 层 | 谁来判 | 为什么 |
|---|---|---|
| 第一层 有无突变 | 脚本 | 直接来自 GDC MAF |
| 第二层 变异功能 | **截短变异脚本自动判**（蛋白被打坏，不可能是"打开"）；**错义/框内变异学生查库判** | MAF 只说明"哪个氨基酸变了"，不说明"变了以后开还是关"；这一步要靠外部证据与判断 |
| 第三层 蛋白定位 | 脚本（UniProt API 自动标注） | 定位是数据库里的事实，能自动就不该人工维护 |

9 个突变候选过这三层（数字为实测）：

```
1. 有非沉默突变                       9 个基因
2. + 变异把蛋白"打开"                  3 个基因   （EGFR、KRAS、PIK3CA）
3. + 大分子够得着（有胞外域）           1 个基因   （EGFR）
```

被砍的三类原因，课上必须分清：

- **功能缺失**：TP53（8 例）、STK11（3 例）、KEAP1（2 例）——都带截短变异（无义/移码）。**判定以变异为单位**：截短的那条变异由脚本从 MAF 自动判为功能缺失（`variant_class`），同基因的错义变异各自查库另判——TP53 的 R156P / R248L / R273C / Y236C 经 ClinVar（Li-Fraumeni 语境）与 CIViC（R156P 有 DOMINANT_NEGATIVE 条目）判为功能受损，C277F / D57N / E258D / N239D 证据冲突或无记录，如实标未明；
- **意义未明（学生查库后判定）**：RET（T350N、E901K）、ROS1（I1374F）、SMARCA4（E1362K）——ClinVar 与 CIViC 都查不到记录，没有功能证据就不能当驱动事件，只能如实标"未知"；
- **模态不匹配**：KRAS（6/14 例有突变数据的肿瘤，G12C/G12S/G12V/G12A）与 PIK3CA（P104L）——功能获得有证据，但都在胞内；**第三层砍的是模态，不是价值**。脚本文末会单独打印这一行对照：同一份数据若改做小分子，留下的是 KRAS 与 PIK3CA。

PIK3CA 那一行值得在课上停一下：它的 P104L 在 ClinVar 里被判为致病（5 个提交者、无冲突），关联的是**生殖系过度生长综合征**（Cowden 综合征 / PIK3CA-related disorder）——那是一个由 PIK3CA 功能获得驱动的疾病，因此这条记录支持"激活"；但它在体细胞层面不是经典热点（E542K/E545K/H1047R），CIViC 里也没有条目。正确的写法是把语境与证据等级一起写出来（`gain_of_function` / `moderate`），而不是一句"VUS"敷衍过去，也不是假装它有肿瘤驱动证据。

所以课程口径是：**按大分子路线，EGFR 是本批数据里最站得住的那个**，而不是"EGFR 是最好的靶点"。任意学生按这张表查一遍都会得到同一结果（实操手册第 4 步），不是教师课前内定。

### 课程现实约束（不是科学判据，必须分开标注）

还有一类信息会影响**我们能不能在课堂里把它讲完**，它必须与上面的判据分开写，否则又会变成"有名的靶点永远赢"：

| 现实约束 | 说明 |
|---|---|
| 有公开实验结构 | 课程二要学生自己叠合、量距离；只有预测模型时无法验证"实验事实"。EGFR 有 1IVO / 1M17 / 4HJO / 1YY9 |
| 课时内可走完 | 表位明确、工具就绪、每步都能复算 |
| 有可引文献 | 学生的每条结论要有出处 |

**这三条决定我们能否开课，不决定靶点好坏。**把它们放进漏斗、或写进报告当作选择依据，就是循环论证。

### 那表达层 top 的候选呢

表达层 top（TERT、HTR3A、TOP2A、CDKN2A、SLC6A3）不是差候选，但它们和本课程三的路线不匹配：

- TOP2A 是**核内**拓扑异构酶，已上市药是依托泊苷/拓扑替康这类**细胞毒化疗药**（小分子、无表位概念）；
- CDKN2A、CCNE1 属细胞周期调控，同样在胞内；
- 它们要确证还依赖"敲除/RNAi 依赖实验"，本课没有这个环节。

所以表达层候选的结局是：**进候选池、写进报告、作为后续依赖实验的对象**，而不是被丢掉。

### 那表达层 top 的候选呢

表达层 top（TERT、HTR3A、TOP2A、CDKN2A、SLC6A3）不是差候选，但它们和本课程三的路线不匹配：

- TOP2A 是**核内**拓扑异构酶，已上市药是依托泊苷/拓扑替康这类**细胞毒化疗药**（小分子、无表位概念）；

所以表达层候选的结局是：**进候选池、写进报告、作为后续依赖实验的对象**，而不是被丢掉。课程二、三选择 EGFR，是因为按上面三层判据它是唯一走完全程的候选；但结论必须表述为"按大分子路线，EGFR 是本批数据里最站得住的那个"——换小分子就是 KRAS。这一点必须在课上讲明，否则学生会以为"排名第一的就是最好的靶点"，也会以为"有药的才叫靶点"。

## 2. 课程一：每个环节的出处

| 课程环节 | 结论 | 依据 |
|---|---|---|
| 数据来源 | 真实 TCGA-LUAD 表达与突变来自 NCI GDC 公开层 | Collisson et al., *Nature* 2014（TCGA LUAD 主论文，PMID 25079552）；GDC 数据门户 `portal.gdc.cancer.gov` |
| 差异分析 | 用负二项模型 + 收缩估计得到 log2FC 与 padj | Love et al., *Genome Biol* 2014（DESeq2，PMID 25516281） |
| 通路富集 | GO BP 用 `clusterProfiler`；第二条通路库用 Reactome（离线注释） | Yu et al., *OMICS* 2012（clusterProfiler，PMID 22455463）；Yu & He, *Mol Biosyst* 2016（ReactomePA，PMID 26661513） |
| EGFR 在 LUAD 是驱动基因 | EGFR 激活突变（19del、L858R）预测 TKI 敏感性 | Lynch et al., *N Engl J Med* 2004（PMID 15118073）；Paez et al., *Science* 2004（PMID 15118125）；综述 Sharma et al., *Nat Rev Cancer* 2007（PMID 17318210） |
| 突变阳性 ≠ mRNA 升高 | 肿瘤可依赖单一激活的癌基因而不改变其转录本丰度（"癌基因成瘾"） | Weinstein, *Science* 2002（PMID 12098689）；Sharma & Settleman, *Genes Dev* 2007（PMID 18079171） |
| EGFR 有获批药 | 厄洛替尼在经治 NSCLC 生存获益；奥希替尼用于 T790M 耐药 | Shepherd et al., *N Engl J Med* 2005（PMID 16014882）；Jänne et al., *N Engl J Med* 2015（PMID 25923549） |
| 耐药机制 | T790M 二次突变导致一代 TKI 耐药 | Pao et al., *PLoS Med* 2005（PMID 15737014） |
| EGFR 信号网络 | EGFR 属 ERBB 家族受体酪氨酸激酶，需配体诱导二聚 | Yarden & Sliwkowski, *Nat Rev Mol Cell Biol* 2001（PMID 11252954） |
| 变异功能判读（学生查询） | 错义/框内变异的"激活"或"未明"以 ClinVar 与 CIViC 的公开记录为依据 | Landrum et al., *Nucleic Acids Res* 2018（ClinVar，PMID 29165669）；Griffith et al., *Nat Genet* 2017（CIViC，PMID 28138153） |
| 蛋白定位与胞外域（自动标注） | 是否有胞外域由 UniProt 库的拓扑结构域条目判定 | UniProt 数据库（发布版本与条目链接记录在 `data/target_context.csv`，本仓库为 release 2026_04） |

| 临床反证：抗 EGFR 抗体与突变状态 | FLEX 三期试验中加用西妥昔单抗的获益与 EGFR **表达水平**相关；EGFR 激活突变**不预测**获益（回顾性分析中为预后因素而非预测因素），后续分析显示获益主要见于高表达组、以野生型为主 | Pirker et al., *Lancet* 2009（FLEX 主试验，PMID 19410716）；O'Byrne et al., *Lancet Oncol* 2011（生物标志物回顾分析，PMID 21782507）；2014 *J Thorac Oncol*（表达与突变状态联合分析，PMID 24662454） |

课程三必须对学生说明的两条边界。第一条是方法学的：**RFdiffusion/ProteinMPNN/Boltz 都是方法学论文里的通用能力，公开文献中并没有"针对 EGFR 的 de novo mini-protein 药物"**，所以产物是"可复核的设计练习 + 一份说明它离药还有多远的方案书"，不是"做出了一个 EGFR 新药"。第二条是生物学的：**本课设计的是结合 EGFR 胞外 domain III 的 binder，而课程一找到的激活突变在胞内激酶域、且为配体非依赖的持续激活（PMID 17332333、16187797）；结合胞外域不等于抑制突变激酶，临床上 EGFR 激活突变也没有预测西妥昔单抗的获益（PMID 19410716、21782507）**。因此课程三的准确定位是"胞外表位的结合剂设计练习"，报告里把它写成"为 EGFR 突变型肺癌设计的治疗方案"属于超范围宣称，按《考核方案》扣分。

## 5. 引用纪律（学生必读，教师必查）

1. **每条结论后面写 `(PMID xxxxx)` 或 `(PDB xxxx)`**；数据库条目给登录号，不给网址截图。
2. **查不到的文献不许写。** AI 助手给的引用必须逐条打开核对：标题、期刊、年份、结论是否真的支持你写的那句话。
3. 核对方式（任选其一）：
   - Europe PMC：`https://europepmc.org/article/MED/<PMID>`，能打开且标题一致才算过；
   - 命令行：`curl -s "https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<PMID>&format=json"`；
   - 结构：`https://www.rcsb.org/structure/<PDB ID>`，核对分辨率、配体、链组成。
4. 引用一条**不支持**你结论的文献，比不引用更糟——报告的"参考文献"一栏按此判分（见《考核方案》）。
5. 预印本（如 Boltz-1）必须标注 `preprint`，不能当成已发表证据使用。
