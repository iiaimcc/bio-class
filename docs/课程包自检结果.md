# 课程包自检结果（2026-11-02）

本文件记录"哪些数字是实际跑出来的、用什么环境跑的"，方便后续改数据/改脚本时知道哪些结论要重算。
所有命令均在 Linux + micromamba 环境执行，离线可复现。

- 突变表覆盖 14/15 例肿瘤：`TCGA-05-4245-01A` 在 GDC 上没有对应 MAF 文件，脚本按"缺失即未知"处理并在 `README` 记录。
- MAF 不含拷贝数变异与融合，因此 `mutation_matrix.csv` 里 0 表示"该基因这些事件类型未检测到/未覆盖"，不能读成"野生型"。
- 脚本在上游输入缺失时会直接报错退出，不再静默产出空结果。
- `results_teacher/` 里额外产出 `deg_symbols.txt`、`mutation_driven_candidates.csv`、`integrated_candidates.csv`、`target_recommendation.csv`，教师参考输出另存于 `course1-omics-target-discovery/materials/fallback/expected/`。
- 漏斗三层各有各的数据源，且尽量去人工化：①突变来自 GDC MAF；②**变异功能按变异判定、再汇总到基因**——截短变异（无义/移码）由 `variant_class` 自动判为功能缺失，剪接位点/起始密码子/非终止变异**不自动判**（效应取决于转录本与阅读框，或根本不是截短），错义与框内变异由学生查 ClinVar/CIViC 后逐条填入 `variant_calls.csv`（模板 `materials/templates/variant_calls_template.csv` 由 `data/make_variant_template.py` 生成，参考答案同目录 `variant_calls_reference.csv`，本机 2026-11-05 用 `data/lookup_variant.py` 与 NCBI E-utilities / CIViC GraphQL 复核）；同一基因同时出现功能获得与功能缺失时汇总为 `mixed` 并在控制台提示复核，不默认归并（本队列没有 mixed 基因）；③定位由 `data/annotate_targets.py` 查询 UniProt 生成 `target_context.csv`（release 2026_04，有胞外域者 6 个：EGFR/ERBB2/ALK/RET/ROS1/MET）。
- 富集分析显式传入 `universe`（过滤后进入检验的 23742 个符号 → 19492 个 Entrez）：不传时 `enrichGO`/`enrichPathway` 会退回整个注释库，同一份 DEG 的显著条目会从 613 涨到 1054（GO BP），虚高约 70%。
- `data/drug_precedent.csv` 只放药物格局参考（获批状态、获批药针对的变异类型），**不参与筛选**（用"已有药"筛选即循环论证：有名的靶点必然赢），只在漏斗之后打印。
- PIK3CA P104L 的证据为"激活但等级 moderate"：ClinVar VCV000217291（Pathogenic/Likely pathogenic，5 个提交者，Cowden 综合征 / PIK3CA-related disorder，属功能获得性疾病；位点 chr3:179199136 与本队列一致），CIViC 无条目，不是体细胞热点。改写这张证据表等于改漏斗结果，必须重跑 03 并同步本文件与 `docs/文献依据.md`。

## 4. 课程三

- `1YY9.pdb`：分辨率 2.61 Å；A/C/D 为蛋白链（624/213/221 个 SEQRES 残基），B/E/F/G 为糖链；A 链 1–618 对应 UniProt 25–642。
- 序列核对：VH（119 aa）与 1YY9 D 链 SEQRES 完全一致；VL（107 aa）与 C 链完全一致；domain III 序列（171 aa）与 UniProt 334–504 完全一致。

- `pymol_interface_commands.pml` 在 PyMOL 3.1.0 下无报错。
- **教师预生成产物已用实物填好**（2026-11-05，本机；此前为空模板）：

## 5. 文献依据

- `docs/文献依据.md` 收录三课每一步结论的出处，PMID 于 2026-11-03 经 Europe PMC 逐条实检（预印本标注 DOI，如 Boltz-1）。
- 第 1 节区分三类信息：**科学判据**（肿瘤与分子自身的事实：有无突变、变异是功能获得/缺失/未明、定位是否匹配所选模态）、**课程现实约束**（结构是否可得、能否在课时内验证、教师手头有无材料——明确标注为非科学判据）、**事后佐证**（临床先例与文献）。漏斗只用第一类：9 → 3 → 1，并写明每一层由谁判定（脚本 / 学生查库 / UniProt 自动标注）。
- 两个被明确拒掉的筛选条件：①"有没有已上市的药"——会把结论当证据，且刷掉所有新靶点；②"能不能查到文献"——文献可得性是靶点出名程度的函数，且属后验。二者只作方向确定后的佐证。
- 模态对照：同一份数据若改做小分子，功能获得 + 胞内的答案变成 KRAS 与 PIK3CA；因此课程口径是"按大分子路线，EGFR 是本批数据里最站得住的那个"，不是"EGFR 是最好的靶点"（课堂讲义与考核答案同步）。
- 已对不上的表述做了校正：公开文献中没有针对 EGFR 的 de novo mini-protein 药物，课程三的产物口径为"设计练习 + 方案书"，该边界写进课堂讲义与考核判分。
