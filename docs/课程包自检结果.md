# 课程包自检结果（2026-11-02）

本文件记录"哪些数字是实际跑出来的、用什么环境跑的"，方便后续改数据/改脚本时知道哪些结论要重算。
所有命令均在 Linux + micromamba 环境执行，离线可复现。

- 三份 R 脚本按手册命令实跑（`Rscript scripts/0X.R <data_dir> <out_dir>`），发布版基准：

| 项目 | 实测值 |

| 显著 DEG（padj<0.05, \|log2FC\|>1） | 116（上调 76 / 下调 40） |
| EGFR 按 padj 排名 / log2FC | 2 / 3.510 |
| 可成药面板 / 真值交集 | 247 / 36 |
| shortlist 候选 | 18；EGFR 按 log2FC 排第 1 |

- 脚本现在会在上游输入缺失时直接报错退出，不再静默产出空结果。

## 3. 课程二

- 兜底输入（`fallback/inputs/`）的 SHA256 与 `fallback/README.md` 一致；`1M17.pdb`、`AF-P00533-F1-model_v6.pdb`、`EGFR_P00533.fasta` 均来自官方源。
- AF v6 的 CA pLDDT 分区均值由文件复算：全局 75.9；1–24 = 44.2；25–645 = 91.0；646–668 = 66.1；669–708 = 52.1；709–968 = 83.7；969–1210 = 37.0。与 `expected/结构事实参考.md` 一致。
- 叠合命令 `align ... resi 712-979 ...` 实测 RMSD = 0.510 Å（208 个 CA）。
- `1M17`：分辨率 2.60 Å；配体 `AQ4` 29 个原子；T790（PDB T766）与配体最近原子距离 3.406 Å；5 Å 口袋 20 个残基（157 个原子）；L858 = PDB L834（偏移 +24）。
- `visual_egfr.pml` 在 PyMOL 3.1.0 下 `pymol -cq` 无报错，三个视角的截图命令均产出图像。

## 4. 课程三

- `1YY9.pdb`：分辨率 2.61 Å；A/C/D 为蛋白链（624/213/221 个 SEQRES 残基），B/E/F/G 为糖链；A 链 1–618 对应 UniProt 25–642。
- 序列核对：VH（119 aa）与 1YY9 D 链 SEQRES 完全一致；VL（107 aa）与 C 链完全一致；domain III 序列（171 aa）与 UniProt 334–504 完全一致。
  - 注意一处构建体差异：UniProt 498 = S，1YY9（PDB 474）= K；比对结构时以 PDB 坐标为准。
- 界面（4.5 Å，仅蛋白原子）：305 个原子对；EGFR 侧 22 个残基、轻链 7 个、重链 14 个；接触原子数 77（EGFR 侧）/ 100（抗体侧）。
- `EGFR_DIII_1YY9.pdb`（310–480，621 个 CA）与 `EGFR_DIII_hotspots.txt`（22 个残基）由 1YY9 与界面表生成，可直接作为 RFdiffusion 目标与 hotspot。
- `CDR标注表.md` 的 IMGT 区间已用 ANARCI 对 VH/VL 标注，并换算到 PDB `resi`（VH: D 26–33/51–57/96–108；VL: C 27–32/50–52/89–97）。
- `pymol_interface_commands.pml` 在 PyMOL 3.1.0 下无报错。
