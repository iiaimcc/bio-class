## 第 1 步：差异表达分析（40 分钟）

### 1.1 认识数据（8 分钟）
在 RStudio 左上角控制台输入：

```r
counts <- read.csv("expression_matrix.csv", row.names = 1, check.names = FALSE)
str(counts)        # 查看结构：10000 行 × 12 列
head(counts, 2)    # 前两行
colSums(counts)    # 每个样本的总 reads —— 观察：一样吗？
```

**预期结果**：`colSums` 各样本约 1 千 5 百万到 1 千 9 百万，**不一样**。想想为什么不能直接拿两个样本的数值相减（手册最后的思考题①）。

### 1.2 运行差异分析脚本（20 分钟）
打开脚本 `01_diff_analysis.R`（Files 面板进入 `scripts/` 子目录点击选中 → Open），然后用终端运行：

```bash
cd /你的-课程数据目录/course1       # 共享目录里含 expression_matrix.csv 与 scripts/ 子文件夹
Rscript scripts/01_diff_analysis.R  .  ./results
```

> 直接在课程包仓库里练习时，CSV 在平级的 `data/` 而不是 `course1/`，把第一个参数换成 `../data`：`Rscript scripts/01_diff_analysis.R ../data ./results`。云端部署时数据会复制进 `course1/`，用 `.` 即可。

或者（更推荐的方式）在 RStudio 里**逐行选中运行**：先设置工作目录（Session → Set Working Directory → Choose Directory，选共享的 `course1` 目录），然后选中代码 → Ctrl+Enter。脚本默认把**当前工作目录**当数据目录、`./results` 当输出目录（即默认参数为 `.` 与 `./results`，与上面的命令一致）；用命令行运行不需要改脚本。如果是逐行选中运行，请先把工作目录设到数据目录，或把脚本顶部 `data_dir`/`out_dir` 两行改成你的实际路径。

脚本会自动完成：建实验设计 → DESeq2 建模 → 输出表格 → 画火山图。

**预期结果（控制台输出）**：

```
Loaded 10000 genes x 12 samples
Significant DEGs (padj<0.05, |log2FC|>1): 116
   up-regulated: 76 | down-regulated: 40
```

并生成两个文件：`deg_table_all.csv`（全部基因的统计表）与 `volcano_plot.png`。

额外核验 EGFR：在 `deg_table_all.csv` 中按 `padj` 从小到大排序，EGFR 应为 rank 2，`log2FoldChange` 约 3.51。这里的 rank 2 是**完整差异结果按校正后显著性排序**，不要与第 3 步 shortlist 的排序混淆。

### 1.3 读火山图（12 分钟）
打开 `results/volcano_plot.png`，对照：

- 右上角红点 = **显著上调**；左上角蓝点 = **显著下调**；灰点 = 不显著；
- `|log2FC|=1` 与 `padj=0.05` 的虚线划分出筛选区域；
- 找到最红的几个点，去 `deg_table_all.csv` 里查它们的 `log2FoldChange`，记录 top3 基因名。
- 写出一句火山图**不能**支持的结论，例如“右上角基因一定是致病驱动基因”。

**记录表（课后交）**：

| 排名 | 基因 | log2FC | padj | 你能猜到它的功能吗 |
|---|---|---|---|---|
| 1 | | | | |

> 卡住了？①`stop("Package ... missing")`：某 R 包没有装，喊老师。②输出表格是空的：检查 `sample_meta.csv` 里的 `condition` 列值是否为 Normal/Tumor（首字母大写）。③`all(colnames(counts) == meta$sample_id)` 报错：说明列顺序对不上，重新执行 `read.csv` 那两行。

## 第 3 步：靶点初筛（25 分钟）

1. 运行脚本 `03_target_shortlist.R`。

```bash
Rscript scripts/03_target_shortlist.R  .  ./results
```

2. 脚本做的事：把 116 个显著差异基因与“可成药面板”（本课文件实测 247 个基因）求交集，按 log2FC 从高到低排序。

3. **预期结果**：控制台打印 TOP 候选靶点表并生成 `results/target_shortlist.csv`，实测共 18 个候选。EGFR 在该表中为 rank 1；这里的排序依据是 shortlist 内的 `log2FoldChange`，而不是完整结果表中的 `padj`。

4. 打开 `target_shortlist.csv`，完成：
   - 写出脚本实测的 top5 上调候选靶点，不要照抄示例或凭印象填写；
   - 用 `panel_class` 列判断：top5 里哪几个属于 receptor_kinase 类？
   - 网页验证（3 分钟）：打开 GeneCards 或 UniProt，搜 `EGFR`，截图"功能一句话"。

**靶点初筛结论模板**（课后报告的第一版结论）：

> 在 116 个显著差异基因（上调 76、下调 40）中，部分基因与已知可成药面板重叠。EGFR 为受体酪氨酸激酶，`log2FC` 约 3.51，在完整差异表按 `padj` 排 rank 2，在 shortlist 按 `log2FC` 排 rank 1，并位于 EGFR/MAPK 相关网络核心，因此进入优先验证列表。反证：EGFR mRNA 高表达可能是肿瘤伴随现象，不能替代蛋白活化、突变分层、功能干预与安全性证据。

> 卡住了？①交集后候选数为 0：多半是 `deg_table_all.csv` 与 `druggable_panel.csv` 的基因名格式不一致（检查是否有引号/空格）。②`inner_join` 报错：先运行 `View(sig)` 和 `View(panel)` 确认两表都存在 `symbol` 列。
