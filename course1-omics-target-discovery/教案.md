# 课程一教案：《基于组学的致病机制解析与靶点发现实践》

- 课时：4 学时（1 次课，180 分钟）
- 对象：本科高年级（生物/药学），已修《生物化学》《分子生物学》
- 场地：云电脑空间（RStudio + 预装 R 包，主链路）；普通机房（网页工具，备选链路）
- 教学目标：学生能独立完成"表达矩阵 → 差异表达 → 富集 → 靶点初筛"标准流程，并理解每一步的统计含义与常见陷阱。

---

## 一、教学目标

### 知识目标（K）
1. 说出转录组测序（RNA-seq）计数数据的三大特点：整数计数、文库深度差异、小样本高维；
2. 解释假设检验、p 值与多重检验校正（BH/FDR）的直观含义，能说明"为什么几千个基因不能只看 p<0.05"；
3. 说出差异表达分析（DESeq2）的流程：文库大小因子 → 离散度估计 → 负二项模型 → 假设检验；
4. 区分"相关性/表达差异"与"因果/成药性"——靶点发现的证据层次；
5. 说明 GO 生物学过程与 Reactome 通路的区别，富集分析的基本假设（超几何检验/最小集合）。

### 技能目标（S）
1. 能在 RStudio 中正确导入 CSV 数据并检查数据结构（str/head/table）；
2. 能运行并理解课程提供的 DESeq2 差异表达脚本，独立修改分组、阈值参数；
3. 能解读火山图（横轴 log2FC、纵轴 -log10 padj、阈值线）；
4. 能用 clusterProfiler/ReactomePA 跑 GO 与 Reactome 富集（本地注释、离线可用），解读 dotplot；
5. 能通过"差异基因 ∩ 可成药面板"完成靶点初筛，写出候选靶点报告（含证据与反证）；
6. 能用 AI 解释或生成小段 R 代码，并通过维度、列名、阈值和输出数量检查完成代码审查；
7. 备选链路：能用 GDC 门户手动取数、用 GEPIA2/Enrichr 复现主要结论（不依赖 R）。

### 素养目标（A）
1. 养成"先理解数据，再跑分析"的科学习惯；
2. 体会可重复性：记录参数、保存脚本与版本；
3. 对"统计显著 ≠ 生物学重要"形成自觉，学会用效应量（FC）与生物学背景双重把关。
4. 形成 AI 使用边界：最小化提供数据、逐行审查代码、本地运行核验、本人承担结论责任。

## 六、常见陷阱与教学重点提示

1. **“p<0.05 就是显著”的误区**——用本课过滤后 23765 个基因现场计算：若全部无差异，逐个按 p<0.05 筛选会期望出现约 1188 个偶然显著；必须讲 BH/FDR。
2. **文库深度**——上课用 `colSums(counts)` 演示 30 个样本总 reads 不同（23M~85M），让学生亲眼看到"不校正不能直接比"。
3. **在线数据库不可达**——富集已改为本地 GO/Reactome，不再依赖在线下载；想补 KEGG 时用 Enrichr 网页端，教师提前验证。GDC 下载若被网络策略拦，切换到兜底副本。
4. **EGFR 之外的“伪靶点”**——学生初筛结果中可能出现炎症或伴随变化基因，这正是教学点：区分“疾病伴随分子”与“驱动分子”，引出反证思维。
5. **把 EGFR 说成“表达上调”**——真实数据里 EGFR 表达不显著；它靠 2/15 例激活突变进入靶点名单。教师必须明确区分“表达证据”和“突变证据”，否则学生会在报告里写下与本机输出矛盾的结论。
6. **AI 代码看似流畅就直接运行**——强制先检查对象名、列名、NA、阈值、文件写入位置，再用维度和 7283/4355/2928 基准核验；AI 不得代写报告。
7. **脚本报错兜底**——常见报错清单及处置见 [docs/故障排查手册.md](../docs/故障排查手册.md)。

## 七、课程间衔接（关键）

- 本课以 **EGFR** 为教师引导的重点候选靶点：它不在表达驱动的 `target_shortlist.csv` 里，而是靠 2/15 例激活突变（19del、L858R）+ 受体酪氨酸激酶属性 + 可成药背景入选，是课程三大分子设计案例——西妥昔单抗——的靶蛋白。课程二建立结构证据，课程三以 EGFR 胞外域为抗原完成抗体设计实践。
- 下课前 2 分钟明确预告：课程二将"验证 EGFR 在蛋白/结构层面的证据"，衔接问题："表达不显著 + 有突变 + 有药 = 靶点成立吗？还缺什么证据？"（答案：蛋白表达/突变活化/通路依赖/结构可成药性）。
- 若课堂时间允许，发放 [课程二实操手册](../course2-structure-validation/实操手册-学生版.md) 前两节（短 URL 清单：UniProt EGFR 页面、AlphaFold DB EGFR）。
