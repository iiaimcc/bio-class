# 课程一教师准备清单

> 原则：**教师用学生身份完整走一遍全部流程**是唯一可靠的验收方式。本清单分为三周/前一周/前一天/当天四档。

---

## 一、开课前两周（一次性）

- [ ] 按 [docs/环境与部署指南.md](../docs/环境与部署指南.md) 完成云电脑软件安装与验证（R ≥ 4.3、RStudio Server、DESeq2/clusterProfiler/org.Hs.eg.db/ReactomePA/reactome.db/ggplot2/pheatmap/dplyr/tidyr/readr）；
- [ ] 拉取课程数据（真实 TCGA-LUAD 子集）。二选一：
  ```bash
  # A. 现场重建（约 130 MB，需能访问 api.gdc.cancer.gov）
  python3 data/fetch_tcga_luad.py --out <共享目录>/course1 --cache ./gdc_cache
  # B. 直接用仓库 data/ 下已核验的发布版文件
  cp data/{expression_matrix.csv,sample_meta.csv,gene_annotation.csv,\
mutation_status.csv,mutation_matrix.csv,druggable_panel.csv} <共享目录>/course1/
  ```
  同时把 `course1-omics-target-discovery/materials/fallback/inputs/` 一并分发，作为学生断网时的兜底；
- [ ] 预热共享只读缓存（整班上课推荐）：`python3 data/fetch_tcga_luad.py --out /tmp/warm --cache <共享目录>/gdc_cache`，课上学生用 `--cache <共享目录>/gdc_cache` 指向它，几秒完成且仍然逐文件核对 md5；
- [ ] 分发到学生共享只读目录（如 `/course-data`），确认**学生账号**可读、可写自己的工作目录；
- [ ] 确认机房备选链路网络可达：`portal.gdc.cancer.gov`、`api.gdc.cancer.gov`、`gepia2.cancer-pku.cn`、`maayanlab.cloud/Enrichr`、`www.genecards.org`（GeneCards 如不可达则换 Open Targets）；
- [ ] 核对 [`docs/文献依据.md`](../docs/文献依据.md)：本课引用的每条结论都能在表里找到 PMID，且逐条打开过；
- [ ] 确认学生任务卡第 3.5 步的 `variant_calls_template.csv` 与 `materials/templates/README.md` 已发放；参考答案在 `materials/templates/variant_calls_reference.csv`，快速批改时对照它；
- [ ] 确认学生任务卡第 4 步的"判据 vs 佐证"表已发放（参考答案即文献依据第 1 节）；强调**上市药与文献不进漏斗**，课上要能解释为什么；
- [ ] 制作 PPT（依据《讲义大纲.md》），替换 P4/P11/P14/P15/P19/P22/P24/P28 为教师本机真实运行截图；
- [ ] 录制 8 分钟《RStudio 界面》微视频（选做）。

## 二、开课前一周（验证运行）

- [ ] 用**学生账号**（权限受限）在云电脑把三个脚本完整跑一遍：
  ```bash
  cd <共享目录>/course1
  Rscript scripts/01_diff_analysis.R  .  ./results_teacher
  Rscript scripts/02_enrichment.R     .  ./results_teacher
  Rscript scripts/03_target_shortlist.R . ./results_teacher
  ```
  数据还没复制进 `course1/` 时，把第一个参数改成 `../data`。
- [ ] 逐项目核对预期输出：
  - `deg_table_all.csv` 行数 = 23765（原始 60660，低表达过滤后进入检验）；显著 DEG = 7283（上 4355 / 下 2928）；
  - EGFR 表达 **不显著**：log2FC ≈ -0.21，padj ≈ 0.56（这是设计好的教学点，不要读成“脚本坏了”）；
  - `volcano_plot.png` 右上红点群清晰，top 上调 MAGEA6/MAGEA3/HOXC12；
  - `go_bp_enrichment.csv` 非空（发布版实测 613 条；若脚本输出是上千条，先检查 `universe` 是否真的传进去了），top 项为细胞外结构组织（extracellular structure organization，159）/细胞外基质组织（158）；`reactome_enrichment.csv` 实测 119 条，top 项为 Extracellular matrix organization；
  - `druggable_panel.csv` 实测 247 个基因；`target_shortlist.csv` 实测 78 个表达驱动候选（top5 TERT/HTR3A/TOP2A/CDKN2A/SLC6A3，**不含 EGFR**）；
  - `mutation_driven_candidates.csv` 里 EGFR 为 2/14（E746_A750del、L858R；分母是 14 例有 WXS 的肿瘤），另有 TP53 8、KRAS 6、STK11 3、RET 2、KEAP1 2、SMARCA4/PIK3CA/ROS1 各 1；
  - `integrated_candidates.csv` 9 行（变异功能 + UniProt 定位齐全），漏斗打印 9 → 3 → 1，`target_recommendation.csv` 只有 EGFR 一行（rank 1），且"expression-driven shortlist overlap: 0 genes"；控制台另打印一行小分子对照（功能获得 + 胞内 = KRAS、PIK3CA）；
- [ ] 明确本课结论口径：**EGFR 的目标地位来自激活突变等驱动证据，而不是表达差异**；课堂结尾必须把这两条分开讲，避免学生把“表达不显著”误当成“EGFR 不是靶点”；
- [ ] 生成机房备选链路材料包：把 `results_teacher/`（表格+图+deg_symbols.txt）打包上传教学平台，供机房学生下载判读；
- [ ] 预填“参考答案”（shortlist top10 + 突变表 + 三层漏斗 + 小分子对照 + top3 通路），用于快速批改。

## 三、课前一天

- [ ] 云电脑重启一次，重新确认 RStudio 可登录、数据目录存在；
- [ ] 检查机房投影笔/投屏、教师演示账号；
- [ ] 准备课上要发的任务卡（教案三处任务卡打印或 PDF 共享）；
- [ ] 打印《实操手册-学生版.md》或确认教学平台可下载；
- [ ] 测试第 0 步取数：机房网络下 `fetch_tcga_luad.py` 直连下载需多久；决定课上用共享缓存（`--cache <共享目录>/gdc_cache`，秒级、仍核 md5）还是兜底副本，并准备好“为什么先看校验值”的说法；

- [ ] 登录云电脑教师账号，打开 RStudio，把三个脚本逐个源运行一遍确认无残留报错（上次运行遗留的 `dev.off()` 中断等问题）；
- [ ] 清空/备妥 `results_teacher`（避免学生看到参考答案）；
- [ ] 确认 `data/` 与 `materials/fallback/inputs/` 都可访问；
- [ ] 打开前测问卷链接（小程序/教学平台），确认可投屏统计；
- [ ] 机房链路：确认 2~3 台机房电脑能打开 GDC 门户和 GEPIA2/Enrichr（长假后网络策略经常变）；
- [ ] 准备 1 名学生演示设备（借给忘带电脑的同学）。

## 六、教师参考答案要点（提前自测用，勿随包发放）

| 检查项 | 预期值 |
|---|---|
| 数据来源 | TCGA-LUAD，15 原发瘤 vs 15 癌旁（GDC STAR counts + MAF） |
| counts 维度 | 60660 × 30 |
| DEG 总数（padj<0.05, \|log2FC\|>1） | 7283 |
| 上调/下调 | 4355 / 2928 |
| EGFR（表达） | log2FC ≈ -0.21；padj ≈ 0.56（不显著） |
| EGFR（突变） | 14 例有突变数据的肿瘤中 2 例：E746_A750del、L858R |
| 富集 top（GO BP） | 背景集 23742 符号 → 19492 Entrez；613 条显著。extracellular structure organization（159 基因）、extracellular matrix organization（158）、regulation of monoatomic ion transport（182）等 ECM/离子转运条目 |
| 富集 top（Reactome） | 119 条显著。GPCR ligand binding（169 基因）、Extracellular matrix organization（138 基因）等 |
| shortlist | 78 个表达驱动候选（不含 EGFR） |
| shortlist top5 | TERT、HTR3A、TOP2A、CDKN2A、SLC6A3 |
| 突变表其他基因 | TP53 8、KRAS 6、STK11 3、RET 2、KEAP1 2、SMARCA4/PIK3CA/ROS1 各 1 |
| 生物学三层漏斗 | 9 → 3 → 1；表达候选与漏斗交集 0 |
| 小分子对照分支 | 功能获得 + 胞内 = KRAS、PIK3CA |
| 判据 vs 佐证 | 判据只用肿瘤/分子事实：突变（脚本）、变异功能（截短自动＋其余查 ClinVar/CIViC）、定位（UniProt 自动）；上市药与文献只作事后佐证，不进漏斗 |
| 综合推荐 | EGFR（rank 1）；TP53/STK11/KEAP1 的**截短变异自动判为功能缺失、其余变异逐条查库**（TP53：1 条自动 + 4 条查库判功能受损 + 4 条未明；STK11：2 条自动 + 1 条未明；KEAP1：1 条自动 + 1 条未明）、RET/ROS1/SMARCA4 查库后全为意义未明、KRAS 与 PIK3CA 因位于细胞内（模态不匹配） |
| 教学引导语句 | "表达层是无假设扫描，给出 78 个有效候选但每个都还要过依赖实验；EGFR 的 mRNA 没有差异，说明这类测量看不见它的变化方式。把它选出来靠的是 14 例有突变数据的肿瘤中 2 例激活突变 + 有胞外域（我们做的是大分子），三层叠起来才轮到它——注意“它有药、它有名”不算理由，那是事后佐证；同一份数据换小分子就是 KRAS 和 PIK3CA。另外记住两句话：能自动判的（截短变异、蛋白定位）不要人工编；查不到的（T350N 这类）只能写未明，不是阴性。" |
