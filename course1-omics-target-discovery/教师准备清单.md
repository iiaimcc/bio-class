# 课程一教师准备清单

> 原则：**教师用学生身份完整走一遍全部流程**是唯一可靠的验收方式。本清单分为三周/前一周/前一天/当天四档。

---

## 一、开课前两周（一次性）

- [ ] 按 [docs/环境与部署指南.md](../docs/环境与部署指南.md) 完成云电脑软件安装与验证（R ≥ 4.3、RStudio Server、DESeq2/edgeR/clusterProfiler/org.Hs.eg.db/ggplot2/pheatmap/dplyr/tidyr/readr/enrichplot）；
- [ ] 用管理员账号生成课程数据并分发：
  ```bash
  python3 data/make_synthetic_expression.py -o <共享目录>/course1
  ```
  分发到学生共享只读目录（如 `/course-data`），确认**学生账号**可读；
- [ ] 确认机房备选链路网络可达：`gepia2.cancer-pku.cn`、`maayanlab.cloud/Enrichr`、`www.geneards.org`（GeneCards 如不可达则换 Open Targets）；
- [ ] 制作 PPT（依据《讲义大纲.md》），替换 P4/P11/P14/P15/P19/P22/P28 为教师本机真实运行截图；
- [ ] 录制 8 分钟《RStudio 界面》微视频（选做）。

## 二、开课前一周（验证运行）

- [ ] 用**学生账号**（权限受限）在云电脑把三个脚本完整跑一遍：
  ```bash
  cd <共享目录>/course1
  Rscript scripts/01_diff_analysis.R  .  ./results_teacher
  Rscript scripts/02_enrichment.R     .  ./results_teacher
  Rscript scripts/03_target_shortlist.R . ./results_teacher
  ```
- [ ] 逐项目核对预期输出：
  - `deg_table_all.csv` 行数 = 10000；显著 DEG = 116（上 76/下 40）；
  - EGFR 在完整差异表按 `padj` 排 rank 2，`log2FoldChange` 约 3.51；
  - `volcano_plot.png` 右上红点群清晰；
  - `go_bp_enrichment.csv` 非空（发布版实测 998 条），top 项为肽类激素响应/胰岛素受体信号，上皮细胞增殖与 ERK 级联条目也显著；
  - KEGG 是否成功（网络）：失败则确定 Enrichr 兜底话术；
  - `druggable_panel.csv` 实测 247 个基因；`target_shortlist.csv` 实测 18 个候选，**EGFR 为 rank 1 且为 receptor_kinase**；
- [ ] 对照模拟数据的真值表 `data/ground_truth_deg.csv`（教师专用），确认学生结果与真值趋势一致（不必逐基因一致）；记住真值表 **不要发给学生**；
- [ ] 生成机房备选链路材料包：把 `results_teacher/`（表格+图+deg_symbols.txt）打包上传教学平台，供机房学生下载判读；
- [ ] 预填"参考答案"（top10 靶点 + top3 通路），用于快速批改。

## 三、课前一天

- [ ] 云电脑重启一次，重新确认 RStudio 可登录、数据目录存在；
- [ ] 检查机房投影笔/投屏、教师演示账号；
- [ ] 准备课上要发的任务卡（教案三处任务卡打印或 PDF 共享）；
- [ ] 打印《实操手册-学生版.md》或确认教学平台可下载；
- [ ] 准备 AI 代码实验：确认学生可访问获准使用的 AI 工具；准备“列名写错”和“阈值未同步”两个审查反例；强调只提供变量结构、报错和少量脱敏示例；
- [ ] 检查掉电预案：确认共享目录正确挂载（掉电后学生文件不丢）。

## 四、上课当天（课前 30 分钟）

- [ ] 登录云电脑教师账号，打开 RStudio，把三个脚本逐个源运行一遍确认无残留报错（上次运行遗留的 `dev.off()` 中断等问题）；
- [ ] 清空/备妥 `results_teacher`（避免学生看到参考答案）；
- [ ] 打开前测问卷链接（小程序/教学平台），确认可投屏统计；
- [ ] 机房链路：确认 2~3 台机房电脑能打开 GEPIA2/Enrichr（长假后网络策略经常变）；
- [ ] 准备 1 名学生演示设备（借给忘带电脑的同学）。

## 五、课后

- [ ] 24 小时内收作业，用"参考答案+真值表"快速批改（考核方案有 rubric）；
- [ ] 反馈 1 分钟问卷：哪一步卡住的人最多 → 把对应步骤写进《故障排查手册》；
- [ ] 记录本班实际运行耗时数字（供调整时间轴）；
- [ ] 把 `target_shortlist.csv` 班级汇总发给课程二教师（三课联动的数据接力）。
