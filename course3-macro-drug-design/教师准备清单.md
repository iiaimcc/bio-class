> 本课涉及在线 RFdiffusion、ProteinMPNN、回折服务和 Boltz/PyMOL。核心原则：**序列与结构由学生课上现场获取，教师预生成结果（相同目标结构与表位约束下的 BoltzGen 替代流程）兜底**。所有结构/序列材料必须真实可溯源，不能把未运行的结果写进答案。

## 二、开课前一周（教师预演）

### 2.1 下载与准备材料（一次性）

1. **抓兜底副本**（课上学生自己下载，教师只准备失败时的副本）：
   `curl -L https://files.rcsb.org/download/1YY9.pdb -o materials/fallback/inputs/1YY9.pdb`
   - 链组成核验：A=EGFR 胞外域，C=Fab 轻链，D=Fab 重链，B/E/F/G 是 N-糖链；
2. **序列**：`materials/EGFR_cetuximab_序列.md` 已填好三条真实序列（domain III = UniProt 334–504、VH = 1YY9 D 1–119、VL = 1YY9 C 1–107），并附复算方法与"UniProt 498 S / 1YY9 474 K"的单点差异说明；
3. **CDR 标注表**：`materials/CDR标注表.md` 已用 ANARCI（IMGT）标注并换算到 PDB `resi`，教师只需抽查几条选择是否非空；
4. **PyMOL 脚本**：`pymol_interface_commands.pml` 已自包含 `load`，可直接用 `pymol -cq` 跑通，输出 `cdr_view.png`；
5. **设计输入**：`materials/fallback/inputs/EGFR_DIII_1YY9.pdb`（1YY9 A 链 310–480）与 `EGFR_DIII_hotspots.txt`（22 个 4.5 Å 表位残基），供 RFdiffusion 做目标与 hotspot；
6. **随堂模板**：`materials/界面约束表_模板.md`、`设计参数记录_模板.md`、`sequence_candidates_模板.csv`，课前确认可分发。

### 2.2 预生成结果（**已完成，见 `materials/fallback/expected/`**）

> 课程包已随附本机生成好的实物（2026-11-05）：`expected/boltz_out/`（Boltz-2 参照复核：iptm 0.972、与 1YY9 叠合 RMSD 0.321 Å）与 `expected/design_out/`（BoltzGen 0.1.2：242 条设计、8 个候选含 6 个计算上自洽的成功案例与 2 个淘汰案例）。以下是**复现或重跑**时的步骤，课上不必再等 GPU。

1. **参照复合物**（Boltz）：把 `EGFR_cetuximab_序列.md` 第 4 节的三条序列填进 `boltz_antibody_template.yaml`，记录 PDB A/C/D 与 Boltz 输入 ID 的映射后再跑。计算节点无外网时，先在能联网的机器用 ColabFold MMseqs2 票据接口生成 `.a3m`，再在 GPU 节点按下面运行：
   ```bash
   conda activate app-boltz
   boltz predict boltz_egfr_cetuximab_msa.yaml \
     --recycling_steps 3 --diffusion_samples 1 --devices 1 --output_format pdb --out_dir out
   ```
   - 记录：iptm、pAE 摘要、与 1YY9 叠合的 RMSD（用 `expected/boltz_out/compare_vs_1yy9.py` 复算）；
2. **binder 设计（教师兜底）**：本包用的是本机 BoltzGen（`conda activate app-boltzgen`，`asglibc239` 容器）：
   ```bash
   boltzgen run spec_egfr_diii_binder_main.yaml --output out --protocol protein-anything --num_designs 150 --devices 1
   ```
   - 规格里 `binding:` 用**链内相对编号**（1–171），不是 PDB 编号；
   - 如坚持课程主线（在线 RFdiffusion + ProteinMPNN + 回折），按 `materials/fallback/README.md` 第 4.1–4.3 节执行，并把产物放进 `expected/design_out/`（标注工具与日期）；
3. **筛选与复核**：用 `expected/design_out/analyze_main.py` / `analyze_designs.py` 复算界面残基与表位重叠；成功/失败案例的选择理由写在 `expected/design_out/README.md` 第 3 节；
4. **不要留占位**：所有"教师填写"栏位在随附材料里都已填成真实数值；如需换成自己重跑的结果，按上面的步骤覆盖并更新日期。

## 六、预演验收基准（红黄绿灯）

| 检查点 | 绿 | 黄 | 红 |
|---|---|---|---|
| RFdiffusion backbone | 至少2个输出，长度合规，至少1个靠近目标表位 | 输出少或表位偏离 | 在线不可用，使用教师预生成 backbone 并标注来源（BoltzGen 替代流程） |
| ProteinMPNN 序列 | 至少3条候选，设计链/固定链记录完整 | 输出少，需教师候选表 | 服务不可用，使用教师输出 |
| 回折与界面 | 至少2条回折，至少1条界面保留 | 结果分歧，写入淘汰理由 | 用教师回折结构做判读 |
| PyMOL 界面分析 | 脚本跑通，接触表可导出 | 需手动点击部分步骤 | 不可用（改用 Mol* 兜底） |
| 机房链路 | Mol* 可交互 | 需教师截图兜底 | 全不可达（打印分发） |

> 黄灯应对：学生仍完成参数、候选筛选和结构审查；红灯应对：使用教师预生成结果（澄清见上：BoltzGen 是替代流程，不是同参数运行），但在提交物中明确写“教师预生成/在线服务失败”。禁止编造运行链接或指标。
