# 课程三教师准备清单

> 本课涉及在线 RFdiffusion、ProteinMPNN、回折服务和 Boltz/PyMOL。核心原则：**序列与结构由学生课上现场获取，教师预生成同参数结果兜底**。所有结构/序列材料必须真实可溯源，不能把未运行的结果写进答案。

---

## 一、开课前两周

- [ ] 确认云电脑 Boltz 可用（复用 `app-boltz` 环境，含权重缓存；验证 `boltz --help`）；
- [ ] 确认 GPU：`nvidia-smi` 正常，显存 ≥ 16 GB；
- [ ] 确认 Google Colab 可登录并能分配 GPU；若不能，确认教师预生成 backbone/sequence/refold 结果完整；
- [ ] 确认 [online_design_links.md](materials/online_design_links.md) 中至少一条 RFdiffusion、ProteinMPNN 和回折路径课前可用；
- [ ] 确认 PyMOL 可用（课程二环境复用）；
- [ ] 确认机房备选链路：RCSB 1YY9 页面可访问、Mol* 可打开（若不可达，教师预生成全部截图并打印分发）。

## 二、开课前一周（教师预演）

### 2.1 下载与准备材料（一次性）

1. **抓兜底副本**（课上学生自己下载，教师只准备失败时的副本）：
   `curl -L https://files.rcsb.org/download/1YY9.pdb -o materials/fallback/inputs/1YY9.pdb`
   - 链组成核验：A=EGFR 胞外域，C=Fab 轻链，D=Fab 重链，B/E/F/G 是 N-糖链；
2. **序列**：`materials/EGFR_cetuximab_序列.md` 已按 1YY9 SEQRES 与 UniProt P00533 填好三条真实序列（domain III 334–504、VH 1–119、VL 1–107），并附复算方法；
3. **CDR 标注表**：`materials/CDR标注表.md` 已用 ANARCI（IMGT）标注并换算到 PDB `resi`，教师只需抽查几条选择是否非空；
4. **PyMOL 脚本**：`pymol_interface_commands.pml` 已自包含 `load`，可直接用 `pymol -cq` 跑通，输出 `cdr_view.png`；
5. **设计输入**：`materials/fallback/inputs/EGFR_DIII_1YY9.pdb`（1YY9 A 链 310–480）与 `EGFR_DIII_hotspots.txt`（22 个 4.5 Å 表位残基），供 RFdiffusion 做目标与 hotspot。

### 2.2 预生成 Boltz 结果（核心，必须在预演周完成）

1. **参照复合物**：如需用 Boltz 重现 cetuximab 参照，把 `EGFR_cetuximab_序列.md` 第 4 节的三条序列填进
   `boltz_antibody_template.yaml`，记录 PDB A/C/D 与 Boltz 输入 ID 的映射后再跑：
   ```bash
   conda activate app-boltz
   boltz predict boltz_egfr_cetuximab.yaml \
     --use_msa_server --recycling_steps 3 --diffusion_samples 5 \
     --max_parallel_samples 1 --output_format pdb --out_dir boltz_out
   ```
   - 若 MSA 服务器不可达：加 `--msa 2 --msa-depth 24` 离线模式（质量略降，教学可接受）；
   - 记录：iptm 数值、pAE 图、与 1YY9 叠合的定性结论（RMSD 量级）；
2. **RFdiffusion 在线设计预演**：按教师固定的目标局部结构、表位约束、60–90 aa 长度和随机种子，生成至少 2 个 backbone；保存 notebook 链接、参数、PDB 和一份失败/淘汰候选；
3. **ProteinMPNN 在线预演**：固定 EGFR 链，只设计 binder 链，生成至少 3 条序列；保存链设置、输出表和选择理由；
4. **回折预演**：用课前实测的 ColabFold 或在线 Boltz 回折至少 2 条序列，保存真实指标、结构和链号；
5. **对比图**：PyMOL 中设计 backbone/回折结构与 1YY9 表位叠合，输出全局和界面图；
6. 以上结果放入 `materials/fallback/expected/design_out/`；Boltz 参照结果放入 `materials/fallback/expected/boltz_out/`，并在讲义里标明工具和日期；
   - **这两个目录目前只有 runbook 与填写清单，没有任何模型文件**：必须在本周内按 `materials/fallback/README.md` 第 4 节实际生成，否则红黄绿灯方案里的"红灯兜底"是空的。
7. 真实数值填入 `materials/boltz_预生成_EGFR_cetuximab.md`，不要留"教师填写"占位。

## 六、预演验收基准（红黄绿灯）

| 检查点 | 绿 | 黄 | 红 |
|---|---|---|---|
| RFdiffusion backbone | 至少2个输出，长度合规，至少1个靠近目标表位 | 输出少或表位偏离 | 在线不可用，使用同参数预生成并标注 |
| ProteinMPNN 序列 | 至少3条候选，设计链/固定链记录完整 | 输出少，需教师候选表 | 服务不可用，使用教师输出 |
| 回折与界面 | 至少2条回折，至少1条界面保留 | 结果分歧，写入淘汰理由 | 用教师回折结构做判读 |
| PyMOL 界面分析 | 脚本跑通，接触表可导出 | 需手动点击部分步骤 | 不可用（改用 Mol* 兜底） |
| 机房链路 | Mol* 可交互 | 需教师截图兜底 | 全不可达（打印分发） |

> 黄灯应对：学生仍完成参数、候选筛选和结构审查；红灯应对：使用教师同参数预生成结果，但在提交物中明确写“教师预生成/在线服务失败”。禁止编造运行链接或指标。
