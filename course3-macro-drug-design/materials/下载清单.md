# 课程三数据下载清单

> 课上的 1YY9 结构与 P00533 序列由**学生现场下载**并记录来源；本清单给出 URL、文件名和校验方法。
> `materials/fallback/inputs/` 是同一来源的教师副本，只用于网络失败时兜底。

## 1. 课上需要下载的文件

在 `~/bio-class-course3/` 下执行（浏览器下载也可以，文件名保持一致）：

```bash
# RCSB PDB：cetuximab Fab – EGFR 胞外域复合物
curl -L https://files.rcsb.org/download/1YY9.pdb -o 1YY9.pdb

# UniProt：EGFR 全长序列
curl -L https://rest.uniprot.org/uniprotkb/P00533.fasta -o P00533.fasta
```

网页入口：

- RCSB 1YY9：<https://www.rcsb.org/structure/1YY9>
- UniProt P00533：<https://www.uniprot.org/uniprotkb/P00533/entry>
- RCSB 1YY9 的 FASTA（可选，用于对照 SEQRES）：<https://www.rcsb.org/fasta/entry/1YY9>
- Boltz 在线：<https://boltz.bio/>（教师课前实测后再给学生链接）

## 2. 记录与校验

```bash
sha256sum 1YY9.pdb P00533.fasta
```

快速检查：

- `grep "REMARK   2 RESOLUTION" 1YY9.pdb` 应为 2.61 Å；
- `grep "^DBREF" 1YY9.pdb` 应看到 A 链映射到 `UNP P00533 25 642`；
- `grep "^SEQRES" 1YY9.pdb` 应有 A（624）、C（213）、D（221）三条蛋白链；
- `grep "^HETATM" 1YY9.pdb | cut -c18-20 | sort -u` 会看到 NAG/BMA/MAN 等糖链残基；
- `grep -c "^ATOM" 1YY9.pdb` 约 7910 条。

## 3. 兜底

网络不可用、下载超时或文件损坏时：

1. 从 `materials/fallback/inputs/` 取 `1YY9.pdb` 或 `P00533.fasta`；
2. 在产出中写明：**用了兜底文件、失败原因、失败时间**；
3. 不得写成"自己现场下载"。兜底文件的网址、抓取日期与 `sha256` 见 `fallback/README.md`。

> 在线设计/回折服务失败时，使用教师预生成结果也必须标注来源（见 `fallback/expected/design_out/README.md`）。
