# design_out：教师预生成的 binder 设计产物（已生成）

本目录是课程三任务卡 2–4 的**红灯兜底**：在线 RFdiffusion / ProteinMPNN / 回折排队或不可用时，学生用同一目标结构、以全部 22 个表位残基为约束的 BoltzGen 替代流程产物完成参数理解、候选筛选和结果复核。在线练习通常只选 4–6 个接触残基；模型、约束和设计数量均不同，不能作同参数比较。产物生成于 2026-11-05。

## 1. 用什么生成的（必须对学生说明）

课程主线是**在线** RFdiffusion（生成 backbone）+ ProteinMPNN（设计序列）+ ColabFold/Boltz（回折）。本目录的兜底产物用本机安装的 **BoltzGen 0.1.2**（`app-boltzgen` conda 环境）一次跑完等价流程：

| 课程主线步骤 | 本目录对应产物 | BoltzGen 步骤 |
|---|---|---|
| RFdiffusion 生成 backbone | `backbones/design_*.cif` | `design`（扩散模型按表位约束生成骨架） |
| ProteinMPNN 设计序列 | `sequence_candidates.csv` 的 `designed_sequence` | `inverse_folding` |
| ColabFold/Boltz 回折 | `refolded/refold_*.cif` | `folding`（Boltz-2 复折叠复合物） |
| 指标与筛选 | `all_designs_metrics*.csv` | `design_folding / affinity / analysis / filtering` |

**不能说成同一个工具**：产物记录里写"本机 BoltzGen 预生成"，学生自己跑在线服务时写"RFdiffusion/ProteinMPNN 在线"。两者是同一类流程（扩散骨架 → 逆折叠 → 复折叠），但不是同一个软件。

|---|---|---|---|---|---|---|---|
| `main_082` | 61 | **0.633** | **2.77** | 0.70 Å | 3 | 15 / 22 | 成功（综合最好） |

长档（80–110 aa）：

| 设计 | 长度 | ipTM | pAE | 自洽 RMSD | 氢键 | 表位重叠 | 角色 |
|---|---|---|---|---|---|---|---|

| `long_86` | 82 | 0.502 | 5.08 | 0.71 Å | **9** | 20 / 22 | 成功（界面最大） |

**骨架阶段（对应学生任务卡 2）是另一套数字**，口径不同不要混用：把设计文件的靶标链叠合到 `../../inputs/EGFR_DIII_1YY9.pdb` 上，只对 binder 链做检查，四个主档骨架的结果是——

| 骨架 | `align` RMSD（靶标 vs 参照） | 骨架阶段表位重叠（靶标侧接触残基 ∩ 22 表位） | 骨架阶段靶标侧接触原子 | `clash`（<2.0 Å 原子数） | `near_epitope`（8 Å 内 binder 原子） |
|---|---|---:|---:|---:|---:|
| `main_082` | 0.20 Å | 17 / 22（23 个接触残基） | 87 | 4 | 240 |
| `main_078` | 0.10 Å | 18 / 22（19 个接触残基） | 58 | 2 | 219 |
| `main_020` | 0.09 Å | 15 / 22（19 个接触残基） | 68 | 1 | 200 |
| `main_101` | 0.19 Å | 17 / 22（22 个接触残基） | 66 | 1 | 199 |

注意 `main_101` 在骨架阶段看着正常（17/22），复折叠后只剩 5/22——**骨架阶段的数据不能用来判断最终是否落在表位上**，这正是两阶段分开记录的原因。运行记录：本机 PyMOL 3.1.0，2026-11-06（`../design_out/README.md` 与此表同源，可复算）。

短距离要逐对复核；下表为对齐到参照 EGFR 后，距离 <2 Å 的全部原子对（binder 使用设计链 A 编号，靶标使用 PDB 编号）：

上表 `clash` 数的是近距离 binder 原子，不是原子对。例如 `main_078` 是 2 个 binder 原子、3 对短距离。`near_epitope` 数的是 8 Å 内 binder 原子；17/22 等表位重叠则是 4.5 Å 接触残基与精确 22 个表位残基的交集。

| 候选 | binder 残基/原子 → EGFR 残基/原子（Å） |
|---|---|
| main_082 | Gly52 O → Gln408 NE2 (1.819)；Leu54 N → His409 NE2 (1.909)；Leu54 O → His409 CD2 (1.746)；Val56 CG1 → Lys465 NZ (1.845) |
| main_078 | Asp36 OD1 → Arg353 NH1 (1.870)；Asp36 OD2 → Arg353 NH1 (1.932)、NH2 (1.738) |
| main_020 | Asp31 OD2 → Lys465 NZ (1.662) |
| main_101 | Ser66 O → His409 CD2 (1.984) |

无短距离可进入下一步；少量局部短距离暂留并检查原子对，可尝试侧链优化或结构松弛后重新计算，未解决前记为“待复核”；出现主链穿插、连续多个残基的主链碰撞，或优化后仍有严重冲突，则淘汰。以上是课堂初筛规则，不是经过验证的统一数值阈值。`main_082` 涉及骨架原子，不能保证只调整侧链就能解决。表中的“成功”指复折叠阶段计算自洽，**不是碰撞已消除或实验结合成功**。

这些原子对比较的是设计与实验参照的兼容性。脚本还单独检查设计文件自带的靶标链：四个主档设计的自身近距离 binder 原子数依次为 `main_082=1`、`main_078=0`、`main_020=0`、`main_101=1`。参照和设计靶标构象不同，两种检查不能混为同一结果。

复算所有八个骨架及原子对：在本目录运行 `python analyze_backbones.py > backbone_review.json`，或在脚本后指定一个或多个骨架 CIF 路径；需要可导入 PyMOL 的 Python 环境。本脚本用于已提供的链 A=binder、链 B=靶标的 BoltzGen 文件，其他来源须先核实链身份。该脚本只输出结果，不修改原始文件；`backbone_summary.json` 保存八个案例的参考结果，其中 `clash_*` 为与实验参照的比较，`complex_clash_*` 为设计复合物内部检查。复折叠阶段继续使用 `analyze_main.py` / `analyze_designs.py`。

两个长度档合计 242 条设计里，同时满足"复折叠自洽（RMSD < 2 Å）+ 界面可信（ipTM > 0.4）"的只有 15 + 5 条；ipTM 中位数约 0.2，复折叠 RMSD 中位数约 1.1 Å。**这正是课上要让学生自己看出来的分布**：有输出 ≠ 成功，成功是少数。

## 5. 课堂用法

1. **参数理解**：把 `spec_*.yaml` 的表位残基与自己的界面约束表逐条对照（编号空间不同：这里是 1–171，PDB 是 310–480）；
2. **候选筛选**：给出八个候选的指标，让学生按"复折叠自洽 → 表位重叠 → 界面化学（氢键/SASA）"排序，说明为什么 `main_082` 综合最好、`main_101` 和 `long_99` 必须淘汰（两种淘汰原因不同：一个没落在表位、一个根本没复折叠）；
3. **结果复核**：叠合 `refolded/refold_main_082.cif` 与 `backbones/design_main_082.cif`，量 RMSD、复算界面残基，与 1YY9 的表位对比；
4. **长度档对照**：同一条表位约束，60–90 与 80–110 两档的成功率与界面大小有差别——请学生解释为什么。

## 6. 边界

- 这些是**计算产物**：ipTM / pAE / RMSD 都不能写成 KD、亲和力、阻断能力或药效；
- 成功案例只是"计算上自洽"，离真实结合还差表达、纯化、SPR/BLI、细胞功能与选择性实验；
- 设计针对 **EGFR 胞外 domain III 的结合剂**，与课程一发现的胞内激酶域激活突变不是一回事（见 `docs/文献依据.md` 第 4 节）。
