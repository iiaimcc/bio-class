> 本文件是任务卡 0–1 的参考输出，由 `fallback/inputs/1YY9.pdb` 实际计算得到。
> 学生先用自己的现场下载文件复算，再对照；数值不同先查链名、`resi`、altLoc 和距离阈值。

复算环境：RCSB `1YY9.pdb`（2026-11-02），PyMOL 3.x / Python 3。


- 这些是**几何接触**，不是"已证实热点"；热点需要丙氨酸扫描或能量分析。

## 3. 复算命令（PyMOL）

```pymol
load 1YY9.pdb
select egfr_chain, chain A and polymer.protein
select antibody, (chain C or chain D) and polymer.protein
select agsurf, egfr_chain within 4.5 of antibody      # 77 个 EGFR 原子
select absurf, antibody within 4.5 of egfr_chain      # 100 个抗体原子
select agsurf_res, byres agsurf                       # 22 个残基 / 170 原子
select absurf_res, byres absurf                       # 21 个残基 / 186 原子
count_atoms agsurf_res
count_atoms absurf_res
iterate agsurf_res and name CA, print("%s%s-%s" % (chain, resn, resi))
iterate absurf_res and name CA, print("%s%s-%s" % (chain, resn, resi))
```

> 两个坑：
> 1. `within 4.5 of chain A` 这种把带空格的表达式直接写在 `of` 后面的写法会被判为 Malformed selection。先把两侧各建成命名选择，再写 `within ... of <名字>`。
> 2. 必须用 `byres` 展开：很多接触残基的 CA 距离大于 4.5 Å，直接 `iterate agsurf and name CA` 只能列出 7 个残基（抗体侧 6 个）。

## 4. 常见错误

| 现象 | 原因 |
|---|---|
| 选 `chain B` 当重链 | 链 B 是糖链；重链是 D |
| 接触残基 0 个 | `within` 两侧用了带空格的表达式，或链名写错 |
| 界面数量明显偏多 | 忘记排除糖链/水，或用了 5 Å 以上阈值 |
| 把 `resi 349` 当成 UniProt 349 | PDB 编号需 +24 才是 UniProt 位置 |
| 认为 1YY9 覆盖全长 EGFR | 只覆盖 UniProt 25–642 |

## 5. 与课程二的口径衔接

- 课程二 1M17 讲胞内激酶域，T790 = `resi 766`；课程三 1YY9 讲胞外 domain III，编号偏移同为 +24；
