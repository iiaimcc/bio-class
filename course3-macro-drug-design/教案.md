# 课程三教案：《人工智能大分子药物设计实践》

- 课时：4 学时（1 次课，180 分钟）
- 对象：本科高年级生物/药学，已完成课程一、课程二
- 场地：云电脑（PyMOL、Boltz、终端）+ 普通机房（浏览器；在线 Colab 需课前确认可访问）
- 范围：只做大分子设计，不做小分子对接
- 设计对象：以 1YY9 的 EGFR domain III 表位为约束，生成新的 mini-protein binder backbone，设计序列并回折筛选
- 参照对象：cetuximab Fab；它是实验结构参照，不是学生要直接优化的“新药”

## 一、教师要讲清楚的核心问题

1. 为什么课程一得到的是候选靶点，而不是已经完成靶点确证；
2. 为什么课程二的 1M17 激酶口袋不能直接拿来设计抗体或 mini-protein；
3. 为什么 1YY9 能提供胞外 domain III 的表位约束；
4. RFdiffusion、ProteinMPNN、回折预测各解决哪一个问题；
5. 为什么一个生成的 PDB、一个高置信度分数和一个漂亮界面都不能直接等于亲和力或药效；
6. **为什么"结合胞外域"不自动等于"抑制突变激酶"**：激活突变在胞内激酶域且为配体非依赖（Okabe 2007, PMID 17332333；Greulich 2006, PMID 16187797），而临床 FLEX 试验中 EGFR 激活突变并未预测西妥昔单抗获益（Pirker 2009, PMID 19410716；O'Byrne 2011, PMID 21782507）——本课的定位是胞外表位结合剂设计练习，不是突变型肺癌治疗方案；
7. 计算结果如何转成表达、结合和细胞功能实验计划；
8. AI 工具（RFdiffusion / ProteinMPNN / Boltz）每一步给出的是什么、输入对不对、结果符合结构事实吗、能支持什么结论、还需要什么实验。

## 二、学习过程中的具体产出

- `界面约束表.md`：从真实 1YY9 提取的表位/接触约束；
- `backbone筛选表.md`：在线或教师预生成 backbone 的参数与淘汰理由；
- `sequence_candidates.csv`：ProteinMPNN 候选及选择理由；
- `refold_review.md`：回折后的结构和界面复核；
- `实验验证计划.md`：表达、SPR/BLI、细胞功能和选择性实验；
- `设计方案书.md`：一页小型设计评审报告；
- `ai_design_notes.md`：AI 辅助理解参数/整理结果的核验记录。

## 三、课前准备

### 两周前

- [ ] 用真实 `1YY9.pdb` 核验链 A=EGFR、C=Fab light、D=Fab heavy；
- [ ] 用 PyMOL 运行 4.5 Å 接触命令，保存教师参考表；
- [ ] 在 [online_design_links.md](materials/online_design_links.md) 列出的 RFdiffusion Colab、ProteinMPNN Colab 和回折服务中至少实测一条主路径；
- [ ] 选定目标局部结构、binder 长度（建议 60–90 aa）、生成数量和随机种子；
- [ ] 课前生成至少 2 个 backbone、3 条序列和 2 个回折结果，作为网页失败时的同参数兜底。

### 课前一周

- [ ] 让一名教师按学生手册完整走一遍：目标结构→backbone→序列→回折→PyMOL；
- [ ] 确认下载文件能在 PyMOL 打开，预测结构链号与残基编号已记录；
- [ ] 准备一个明显失败的候选（远离表位、碰撞或回折脱离界面），用于教学生淘汰而不是只展示成功样例；
- [ ] 确认 `materials/设计参数记录_模板.md` 与 `materials/sequence_candidates_模板.csv` 已随课程包分发（学生复制后填写）；
- [ ] 准备网页不可达时的截图、PDB、候选序列和回折结构。

## 五、教师讲解与评价重点

### 5.1 RFdiffusion 的成功标准

看四件事：目标约束是否真的用上、backbone 长度是否合规、有没有明显穿模或碰撞、是否靠近目标表位。有输出文件不等于这一步成功。

### 5.2 ProteinMPNN 的成功标准

不只看分数高低，还要看候选序列的内部核心是否合理、界面化学是否讲得通、能不能回折，并至少保留一个对照候选。

### 5.3 回折的成功标准

不是“pLDDT高所以有效”，而是回折结构保持设计形状并接近目标表位。不同候选和不同随机种子的一致性比单个漂亮模型更有信息。

### 5.4 实验计划的成功标准

必须区分：能表达、能结合、能阻断、对其他 ErbB 有选择性。这些是不同实验问题，不允许用一个计算分数代替。

## 六、AI辅助编程和科研记录

学生可以用 AI 解释 notebook 参数、检查 CSV 字段、生成 PyMOL 选择命令或整理运行日志。每次使用都要保留：

1. 给 AI 的脱敏提示；
2. AI 返回的代码或解释；
3. 人工核验的事实来源；
4. 实际运行输出；
5. 最终采用/拒绝的理由。

禁止让 AI 编造指标、链号、表位、实验结果或设计成功结论。教师评分 `ai_design_notes.md` 的重点是核验质量，不是提示词花样。

## 七、课程三与前两课衔接

- 课程一的表达/突变证据说明 EGFR 值得研究，但不能说明 mini-protein 已经有效；
- 课程二的 1M17 说明激酶域有实验支持的胞内小分子口袋，但它不是本课抗原表位；
- 本课的 1YY9 提供 EGFR 胞外 domain III 的抗体界面参照；
- 课程结束时学生应能交出一个“待实验验证的候选设计”，而不是声称完成药物开发。

## 八、备用链路

- RFdiffusion Colab 不可用：教师提供同参数 backbone，学生完成参数和结构审查；
- ProteinMPNN 不可用：教师提供候选序列表和设计链信息，学生做候选筛选；
- 回折服务不可用：教师提供回折结构，学生完成界面复核；
- PyMOL 不可用：使用 RCSB Mol* 做观察，接触表采用教师预计算结果；
- 所有备用结果必须标明“教师预生成/在线服务失败”，不得写成学生现场运行结果。

常见故障见 [docs/故障排查手册.md](../docs/故障排查手册.md)。
