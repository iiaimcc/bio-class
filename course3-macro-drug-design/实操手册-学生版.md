## 任务卡 1：从 1YY9 提取可复核的表位约束（30 分钟）

### 1.1 先确认链，不要复制旧命令（5 分钟）

```pymol
load 1YY9.pdb
get_chains 1YY9
hide everything
show cartoon, 1YY9
color marine, chain A
color palecyan, chain C
color salmon, chain D
```

如果蛋白链不是 A、C、D，停止并报告老师。不要因为旧脚本里写了 B 就强行运行——链 B 是 N-糖链，不是重链。

### 1.2 计算 4.5 Å 接触区（15 分钟）

```pymol
select egfr_chain, chain A and polymer.protein
select antibody, (chain C or chain D) and polymer.protein
select egfr_contact, egfr_chain within 4.5 of antibody
select antibody_contact, antibody within 4.5 of egfr_chain
show sticks, egfr_contact or antibody_contact
count_atoms egfr_contact
count_atoms antibody_contact
iterate egfr_contact and name CA, print(chain, resi, resn)
iterate antibody_contact and name CA, print(chain, resi, resn)
```

参考值（同一版 1YY9 文件）：EGFR 侧 77 个接触原子、抗体侧 100 个；数值接近即可。差很多时先查有没有把糖链/水算进来——`polymer.protein` 就是用来排除它们的。

教师参考的 EGFR 接触区包括 A349、A353、A382/A384、A408–A418、A438–A443、A465–A473。你要以自己的运行输出为准，因为距离阈值、缺失原子和结构文件版本都会影响数量。

### 1.3 把接触区转成设计规格（10 分钟）

完成 `界面约束表.md`（复制 `materials/界面约束表_模板.md` 后填写）：

| 约束 | 来源 | 对设计的影响 |
|---|---|---|
| 目标抗原链 | 1YY9 chain A | RFdiffusion 固定目标结构 |
| 目标表位 | 4.5 Å 接触残基 | binder 尽量接近该区域 |
| 参考抗体 | chain C/D | 只作空间参照，不复制成新抗体 |
| binder 长度 | 教师指定，例如 60–90 aa | 过滤过长/过短 backbone |
| 成功标准 | 能回折且界面保留 | 不能写成“已证明有亲和力” |

**重要区别**：接触残基是几何事实；热点是需要实验或更强证据支持的假设。不要把表格标题写成“已证实热点”。

**产出**：`界面约束表.md`、`截图1-1YY9界面.png`。

## 任务卡 2：在线 RFdiffusion 生成 backbone（35 分钟）

### 2.1 打开在线 notebook（5 分钟）

打开教师提供的 `online_design_links.md`，进入 ColabDesign RFdiffusion notebook：

`https://colab.research.google.com/github/sokrypton/ColabDesign/blob/main/rf/examples/diffusion.ipynb`

教师会提供：

- 目标结构 `materials/fallback/inputs/EGFR_DIII_1YY9.pdb`（1YY9 A 链 310–480，171 aa，编号保持 1YY9 原样）；
- hotspot 清单 `materials/fallback/inputs/EGFR_DIII_hotspots.txt`：22 个 4.5 Å 表位残基，课堂小规模试跑先挑 4–6 个连续的；
- 设计长度范围，例如 60–90 aa；
- 生成数量和随机种子要求。

不要在课堂上自行改变一大串参数。先把输入、输出和参数记录清楚。

### 2.2 运行或使用教师结果（20 分钟）

优先顺序：

1. 能打开 Colab：运行教师指定的小规模任务，下载 1–3 个 backbone PDB；
2. Colab 排队或网络不稳：使用教师同一参数预生成的 backbone，完成结果审查；
3. 两者都不可用：完成输入参数解释和失败分析，不伪造“我运行成功”。

为每个结果记录：

| 候选 | 文件名 | 长度 | 随机种子 | 是否靠近目标表位 | 明显碰撞/断裂 | 去留 |
|---|---|---:|---|---|---|---|
| bb_1 | | | | | | |
| bb_2 | | | | | | |

### 2.3 结构审查（10 分钟）

在 PyMOL 中加载目标和 backbone，观察：

```pymol
load materials/fallback/inputs/EGFR_DIII_1YY9.pdb, egfr
load bb_1.pdb, bb1
select clash, bb1 within 2.0 of egfr
count_atoms clash                       # 明显碰撞：>0 就要记录并解释
select epitope, egfr and resi 349+353+382+384+408-418+438-443+465-473
select near_epitope, bb1 within 8 of epitope
count_atoms near_epitope                # 0 表示离表位太远
```

- backbone 是否穿入 EGFR（`clash` 非空说明有原子间距 <2.0 Å）；
- 是否离目标表位太远（`near_epitope` 为空说明没靠近 hotspot）；
- 是否存在严重原子碰撞；
- 不同随机种子是否给出相似或完全不同的构象。

**不能得出的结论**：有一个漂亮 backbone，不等于它有序列、不等于能表达、不等于能结合。

**产出**：`backbone筛选表.md`、至少一个 backbone PDB、运行链接/截图和参数记录。

## 任务卡 5：把计算候选写成实验计划（20 分钟）

计算候选只能进入“待验证列表”。写一页 `实验验证计划.md`，必须包括：

1. 蛋白表达和纯化：表达系统、SEC/SDS-PAGE、聚集检查；
2. 结合实验：SPR 或 BLI，EGFR 胞外域、cetuximab/已知配体阳性对照、浓度梯度；
3. 突变验证：对新 binder 接触残基和 EGFR 表位候选做 Ala 扫描；
4. 功能实验：EGF 刺激下 EGFR 磷酸化、细胞增殖或存活读数；
5. 选择性：EGFR 阴性/低表达细胞和其他 ErbB 家族成员对照；
6. 失败标准：不能表达、聚集、无结合、结合但无阻断，分别如何处理。
