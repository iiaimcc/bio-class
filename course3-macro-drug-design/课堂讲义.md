# 课程三讲义：自己在 EGFR 表面上造一个结合蛋白

四个学时，180 分钟。这门课不碰小分子，那部分内容由另一门课负责。

## 今天要干的事

前两节课拿到了两样东西：EGFR 是个值得做的靶点——课程一用四层证据（突变、可成药、细胞表面、药物类型匹配）把它筛成唯一推荐；以及 EGFR 长什么样、哪里能碰（课程二）。

今天换个方向——不看胞内那个激酶口袋了，去看细胞外面。

问题是这么来的：抗体这类大分子进不了细胞，所以它只能打胞外。EGFR 的胞外是 domain I 到 IV，其中 domain III 是西妥昔单抗结合的地方，也参与配体识别。

那今天要做的事就清楚了：

> 拿 `1YY9` 里西妥昔单抗贴在 EGFR 上的那片区域当参照，设计一个**全新的小蛋白**去结合那个位置。

注意用词：是全新的小蛋白（mini-protein binder），不是"改造西妥昔单抗"，也不是"AI 生成一个抗体"。

西妥昔单抗在这里的角色是路标——它告诉我们"这个位置可以被蛋白结合"，并且提供了一个真实的界面给我们对照。它不是学生的设计起点，更不是学生要优化的对象。

流程是这条：

```
1YY9 里量出接触区  →  定设计约束
        ↓
在线跑 RFdiffusion，生成一批蛋白骨架
        ↓
用 ProteinMPNN 给骨架配序列
        ↓
把序列丢回结构预测工具，看还能不能折回来、界面还在不在
        ↓
PyMOL 里数接触残基，和 1YY9 对照
        ↓
写实验方案：怎么表达、怎么测结合、怎么证明它真能阻断信号
```

每一步都会翻车，翻车的方式还挺多样。下面一个一个说。

---

# 第一学时：先把"设计什么"讲清楚

## 为什么不做抗体

学生第一反应通常是"那就设计一个抗体呗"。

完整抗体要处理的问题：重链轻链怎么配对、CDR 环怎么设计、人源化、免疫原性、糖基化、Fc 功能、表达和聚集……每一项都能单独开一门课。

四个学时不可能把这些假装解决掉。

mini-protein 就好办一些：长度短，通常几十个氨基酸，只有一条链，不用操心配对和 Fc。设计目标也单一：折得稳、贴得上、位置对。

这仍然是真实的蛋白设计流程，只是把问题边界收窄到一节课能做完的程度。做完之后，学生手里是一个**待验证的候选**，不是能进临床的药。

这句话我要在课上说三遍，因为每年都有学生到最后写成"我们设计了治疗肺癌的新药"。

---

## 1YY9 的真实情况

```pymol
load 1YY9.pdb, 1YY9    # 学生当场从 RCSB 下载；失败时用 materials/fallback/inputs/1YY9.pdb
get_chains 1YY9
```

链是 A、C、D：

| 链 | 是什么 |
|---|---|
| A | EGFR 胞外区，构建体对应 UniProt 25–642 |
| C | 西妥昔单抗 Fab 轻链 |
| D | 西妥昔单抗 Fab 重链 |

分辨率 2.61 Å（PDB 1YY9；Li 2005, *Cancer Cell*, PMID 15837620）。

先上色看一眼：

```pymol
hide everything
show cartoon, 1YY9
color marine, 1YY9 and chain A
color palecyan, 1YY9 and chain C
color salmon, 1YY9 and chain D
```

然后量接触区：

```pymol
select egfr_chain, 1YY9 and chain A and polymer.protein
select antibody, 1YY9 and (chain C or chain D) and polymer.protein
select egfr_contact, egfr_chain within 4.5 of antibody
select antibody_contact, antibody within 4.5 of egfr_chain
select egfr_res, byres egfr_contact
count_atoms egfr_res                  # 22 个残基、170 个原子
iterate egfr_res and name CA, print("%s%s-%s" % (chain, resn, resi))
```

这里有两个坑要现场强调：`within 4.5 of chain A` 这种把带空格的表达式直接写在 `of` 后面会报 Malformed selection，必须先把两侧建成命名选择；另外一定要 `byres` 展开——很多接触残基的 CA 本身离抗体超过 4.5 Å，`iterate egfr_contact and name CA` 只数得出 7 个。

跑出来的 EGFR 侧接触残基，集中在这么几段：

```
A349、A353
A382、A384
A408 到 A418
A438 到 A443
A465 到 A473
```

等一下，先别急着抄这几个数。

这些数字是"4.5 Å 阈值下算出来的接触残基"，是几何事实。换 4.0 Å 或者 6.0 Å，数字会变；换一个分辨率更高或者带糖链的结构，数字也可能变。

更重要的是：**接触不等于热点**。

接触是"离得近"。热点是"改掉它以后结合明显变差"。这两个概念之间隔着一堆实验。今天算出来的东西，正确的叫法是"接触残基候选"或者"表位候选"，报告里别写成"我们找到了热点"。

这句话第三遍：**接触 ≠ 热点**。

---

## 把观察变成设计约束

接下来的问题是：怎么把"西妥昔单抗贴在这片区域"变成一个能让程序读懂的指令？

填这张表：

| 项目 | 今天填什么 |
|---|---|
| 目标蛋白 | EGFR 胞外 domain III 附近 |
| 参考结构 | 1YY9，A 链 |
| 目标区域 | 上面那几段接触残基围出来的表面 |
| 要生成的东西 | 一个新的蛋白骨架，长度由老师指定，比如 60–90 个氨基酸 |
| 不动的部分 | EGFR 结构本身 |
| 什么算成功 | 骨架生成出来、靠近目标区域、没有明显穿模、后续能配上序列并折回来 |
| 什么不算成功 | 生成文件有了、分数高——这些都不算 |

最后两行最重要。学生很容易把"程序跑完了"当成"做成了"。

# 第二学时：RFdiffusion，生成骨架

## 它生成的是什么

RFdiffusion 是扩散模型，做的是蛋白主链的几何（Watson 2023, *Nature*, PMID 37433327；序列设计用 ProteinMPNN，Dauparas 2022, *Science*, PMID 36108050；复合物复核用 Boltz-1，Wohlwend 2024 预印本 DOI 10.1101/2024.11.19.624167，对照 AlphaFold3，Abramson 2024, PMID 38718835）。

**先把边界说清楚**：RFdiffusion、ProteinMPNN、Boltz 都是方法学论文里的通用能力，公开文献中**没有**"针对 EGFR 的 de novo mini-protein 药物"。所以本课的产物是"可复核的设计练习 + 一份说清它离药还有多远的方案书"，不是"做出了一个新药"——报告里任何超出这个范围的表述都会被扣分。

可以这么理解：它见过大量真实蛋白的骨架，学会了"什么样的主链形状是合理的"。你给它一个目标结构和一个大致区域，它就从噪声里一点点雕出一段新的主链，让它贴在指定位置上。

**它生成的是骨架，不是序列。**

生成的骨架，氨基酸位置上是空的，或者全是甘氨酸占位。序列要下一步补。

这件事说起来简单，但学生第一次看结果时经常搞混：拿到一个 `.pdb` 文件，用 PyMOL 打开，发现能看，就以为设计完成了。

打开看看就知道了——里面看不出什么有意思的残基，因为序列还没定。

课上的验证动作：

1. 打开生成的骨架；
2. 和 EGFR 一起显示；
3. 看它是不是贴近目标区域，有没有穿进 EGFR 里面去；
4. 数一数长度对不对。

## 实际怎么跑

用公开的 ColabDesign 版本：

```
https://colab.research.google.com/github/sokrypton/ColabDesign/blob/main/rf/examples/diffusion.ipynb
```

课前老师要实测一遍链接能不能开、GPU 排不排得上队、文件能不能下载。这些都不是必然成功的。

课堂上的做法是固定的：目标结构、长度范围、生成数量、随机种子，全由老师给定。**不让学生在课上自由改参数**，否则四个学时全耗在等结果上。

跑完之后，每一条生成结果都要填进 `backbone筛选表.md`：

| 候选 | 文件名 | 长度 | 种子 | 靠近目标区域吗 | 有碰撞吗 | 留还是扔 |
|---|---:|---|---|---|---|---|
| bb_1 | | | | | | |
| bb_2 | | | | | | |

最后那一列才是关键。**被扔掉的候选和留下的候选一样重要**，因为淘汰理由说明学生真的看懂了判断标准。

---

## 在线服务挂了怎么办

一定会有学生举手说"我这边打不开"。

所以课上的优先级是三档：

1. 能开、能跑：自己跑，下载结果，记录参数和种子；
2. 开不了但排队能用：等一等，或者用老师同参数预生成的骨架，继续做后面的分析；
3. 完全打不开：用老师的预生成结果，但在报告里**写明是老师预生成的**。

第三档是底线。写清楚来源不丢人，把老师的结果写成本人现场运行的结果，才是问题。

这门课有个原则：**计算失败不是科学失败**。工具挂了、配额用完了、网络被墙了，这些都是工程问题。真正的科学判断是：拿到骨架以后，你怎么看它。

# 第三学时：ProteinMPNN 配序列，然后折回去验一遍

## 给骨架构思序列

ProteinMPNN 干的事叫逆折叠：给定一个主链形状，猜什么样的氨基酸序列能折成这个形状。

用它自己的 Colab：

```
https://colab.research.google.com/github/dauparas/ProteinMPNN/blob/main/colab_notebooks/quickdemo_wAF2.ipynb
```

关键设置：**目标 EGFR 链固定不动，只设计 binder 那条链**。别把整个复合物都拿去重新设计，那样 EGFR 那边也被改了，就没法比较了。

跑出来一批序列，通常会问："选哪条？"

这里有个陷阱：学生看到一列分数，顺手就选最高的。

分数是 ProteinMPNN 对"这条序列和这个骨架搭不搭"的估计。它不管这条序列好不好表达、会不会聚集、贴上去以后有没有电荷冲突。

所以选择的时候至少看四件事：

- 设计分数（参考，不是唯一标准）
- 内部核心填得饱不饱满（核心空着，蛋白多半折不稳）
- 界面上有没有暴露一堆疏水残基（有的话容易聚团）
- 序列里有没有奇怪的重复或者极端组成

选两条进下一步，再留一条"为什么不选它"，一起写进 `sequence_candidates.csv`。

---

## 折回去，看它还算不算数

序列设计完，不能直接说"设计完成"。要把序列再塞回结构预测工具（Boltz-1，预印本 DOI 10.1101/2024.11.19.624167），看两件事：

**第一，它自己折得回来吗？** binder 部分能不能形成原来设计的形状。

**第二，界面还在吗？** 它是否还贴在原来的目标区域上。

这步叫回折验证。用 ColabFold，或者用在线 Boltz 服务，具体用哪个以老师课前实测为准。

学生在这里最容易犯两个错：

第一个：**把工具名写错**。用 ColabFold 跑的结果写成"用 Boltz 预测"。名字必须如实写，这是基本学术规范。

第二个：**把置信度当结论**。"pLDDT 很高，说明设计成功"——不对。pLDDT 说的是"这个结构自己内部一致"，它不管这个结构是不是你想要的那个。

正确的问法是三连：

1. binder 自己折成形了吗？
2. 它贴在目标区域吗？
3. 它和设计时的骨架差得多不多？

三条都过，才算一个能往下走的候选。

回折结果填进 `refold_review.md`：

| 检查项 | 观察到什么 | 结论 |
|---|---|---|
| binder 自己折叠好了吗 | | |
| 贴住目标区域了吗 | | |
| 和设计骨架一致吗 | | |
| 接触残基落在目标区吗 | | |
| 两条候选结果一致吗 | | |

---

## 在 PyMOL 里数接触

这一步会踩一个坑，而且是每次都会踩：

**预测出来的结构，链名和 1YY9 不一样。**

1YY9 是 A、C、D。可回折工具的输入是你自己交的序列，输出可能是 A、B，也可能被重新编成 1、2。所以别把旧命令直接复制过来。

先查：

```pymol
get_chains model_1
```

看清楚哪条是 EGFR、哪条是 binder，然后再写：

```pymol
select egfr_new, model_1 and chain <EGFR的真实链>
select binder_new, model_1 and chain <binder的真实链>
select binder_contact, binder_new within 4.5 of egfr_new
select egfr_contact_new, egfr_new within 4.5 of binder_new
count_atoms binder_contact
count_atoms egfr_contact_new
```

尖括号里是占位符，要替换成真实链名。**直接复制粘贴不替换，是这门课最常见的低级错误**，命令不报错，结果全空。

数出来以后，和 1YY9 的接触区对比：

- 重叠：说明新 binder 大致瞄着同一个位置；
- 不重叠但很近：可能贴着旁边的表面，也值得讨论；
- 差很远：这个候选就淘汰了。

这里又要强调一遍：**重叠也只能说明"可能竞争"，不能说"一定阻断"**。结合和阻断是两件事，前者是结构问题，后者是功能问题。

# 第四学时：从计算走到实验，以及这门课的收尾

## 计算能带你走多远

一个候选经过上面几步，手里有了：骨架、序列、回折结构、接触残基、和 1YY9 的对照。

看起来很完整了。但要记住这条线的位置：

```
计算得到的是一个"值得试一试"的假设
```

它靠什么活下来？靠实验。

课上会让学生把这句话抄在报告开头。

---

## 实验方案怎么写

写实验方案最容易犯的错是"写得很全，但每一条都不具体"。所以给一个硬性要求：每一步都要写清楚它要排除哪种失败。

**表达和纯化。** 合成基因、选表达系统（大肠杆菌或者别的）、纯化。然后做 SEC 和 SDS-PAGE 看纯度和聚集。要排除的失败：蛋白根本表达不出来，或者一纯化就聚成一团。

**结合实验。** SPR 或者 BLI 测亲和力。必须带对照：阳性对照（比如西妥昔单抗或者已知配体），还有浓度梯度。看的是 KD，不是"有没有信号"。要排除的失败：会不会只是贴在管壁上、贴得没有特异性。

**突变验证。** 挑几个接触残基突变成丙氨酸，看结合掉不掉。这步才回答"这些残基到底重不重要"，也就是前面反复提醒的"热点"问题。要排除的失败：这些残基是不是只是路过，其实可有可无。

**功能实验。** EGF 刺激下测 EGFR 磷酸化，再看细胞增殖。到这里才回答"能不能阻断信号"。要排除的失败：结合了但不影响功能——这种情况在真实项目里很常见。

**选择性。** 用 EGFR 阴性或者低表达的细胞做对照，再看看和其他 ErbB 家族成员有没有交叉反应。要排除的失败：这个 binder 谁都结合，那它就没有选择性可言。

五个部分写完，一页纸就够。关键不是篇幅，是每一段都要回答"我为什么要做这个实验"。

## 让 AI 干活，但要留痕

这门课允许 AI 帮忙做这些事：

- 解释 notebook 里的参数
- 把 PyMOL 需求翻译成命令
- 整理结果表格
- 分析报错

不允许代劳的：

- 猜链号、残基号
- 编造指标数字
- 把预测写成实验结论
- 直接写结果段落

用 AI 的代码提示：

```
这是某次运行的记录和一个脱敏后的结果表。
帮我解释每一列的含义，指出我还缺哪些验证信息。
不要补充我没提供的数值，也不要把预测指标说成亲和力或者药效。
```

每次用完，在 `ai_design_notes.md` 里留四样东西：给 AI 的提示、AI 的回复、你不是从哪里核对的事实、最后用没用它、为什么。

评价的重点不是提示词写得漂不漂亮，而是**你有没有核对**。

---

## 报告怎么写

报告的骨架就是整个流程，一段一步：

1. 我要设计什么，目标区域在哪（从 1YY9 来）
2. 骨架怎么生成的，参数是什么，淘汰了哪些
3. 序列怎么选的，为什么
4. 回折结果怎么样，界面还在不在
5. 和西妥昔单抗的界面比，重叠在哪里
6. 哪些结论是计算支持的，哪些必须做实验
7. 实验怎么做
8. 运行链接、文件名、工具版本、日期

最好的报告往往不是选了"分数最高"的那个候选，而是能把淘汰过程讲清楚的。能说清"我为什么不要它"的学生，通常也说得清"我为什么留下它"。

## 下课前的四个问题

1. RFdiffusion、ProteinMPNN、回折预测，这三个分别解决什么问题？哪个跟亲和力最没关系？
2. 你的 binder 和 1YY9 表位重叠了，为什么只能说"可能竞争"？
